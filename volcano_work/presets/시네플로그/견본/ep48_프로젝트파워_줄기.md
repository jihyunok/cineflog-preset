# 48 프로젝트 파워 — 새 줄기 (11-05, 사용자 확인용)
규칙: 사건마다 「왜 → 그래서」. 영화가 보여 주거나 말한 것만. 곁가지(교실 랩·공항 구매자·가짜 경찰·카르텔 손님)는 처음부터 뺌.

1. 공짜 알약 「파워」가 뉴올리언스에 풀림 — 공급책 비기가 딜러들에게 공짜로 뿌림 → 먹으면 5분 동안 몸속 동물 능력이 나오고, 못 견디면 터져 죽음 → 도시에 이상한 사건이 빗발침
2. 로빈 — 아픈 엄마 약값을 벌려고 알약을 파는 10대, 꿈은 래퍼 → 단골 손님이 형사 프랭크
3. 프랭크 — 범인들도 약을 쓰니 자기도 몰래 먹음(방탄 피부) → 은행 강도를 잡지만 반장에게 들킴 → 반장은 「비공식으로 같이 하자」며 경찰이 쫓는 사진 속 남자를 보여 줌 = 아트
4. 아트 — 알약 출처를 쫓아 딜러 뉴트(로빈의 사촌)를 찾아감 (★여기선 「왜 쫓을까요?」 궁금증만 남김) → 뉴트가 알약을 먹자 몸에서 불, 방이 불바다 → 아트는 공급책 이름 「비기」와 뉴트의 휴대폰을 얻고, 뉴트는 숨짐
5. 그날 아침 로빈의 집 — 엄마가 뉴스를 보며 「네 사촌 뉴트 집에 불」 → 로빈이 뉴트에게 문자 → 뉴트 폰을 가진 아트가 답해 로빈을 불러냄 → 로빈을 트럭 짐칸에 가둠
6. 아트는 로빈을 협박해 비기 쪽으로 가는 길잡이로 삼음 → 로빈은 몰래 프랭크에게 구조 문자 → 뉴트의 비상 연락처 = 홍콩 마켓
7. 마켓 뒤 유통책 사무실 — 로빈이 아트를 일러바침 → 싸움(뼈칼 사내) 속 아트 총상 → 감시 모니터에서 진실: 알약마다 칩, 사 먹는 사람들 = 실험 쥐, 오늘 밤 구매자 시연 → 다친 아트가 로빈을 딸로 착각, 로빈 달아났다 붙잡힘 → 아트가 구함
8. 아트가 처음 이유를 말함: 「딸을 찾으려는 거야」 → 로빈 마음을 돌려 동물병원에서 상처를 꿰매 줌
9. 그 밤, 로빈의 능력은? 「몰라요, 먹은 적 없어요」 → 아트가 단어를 던지고 로빈의 즉석 랩 → 「그게 네 능력이야」(명장면)
10. 아트의 과거 — 군에서 회사 텔레이오스의 실험을 받음 → 그 뒤 태어난 딸은 약 없이도 능력 → 회사가 딸을 노려 도망치다 차가 뒤집혀 딸을 빼앗김 → (★4번 답) 그래서 알약을 쫓는 것
11. 로빈이 길 안내를 맡고 둘은 시연장으로 / 프랭크는 휴대폰 위치로 로빈을 찾아내 「그 남자 나빠」 → 로빈 「딸 찾는 아빠예요」
12. 시연장 — 구매자들 앞 탱크 시연 → 아트가 숨긴 총으로 비기를 인질로 → 총격전 → 비기 입에서 「실험은 제네시스호라는 배에서」 → 프랭크가 들이닥침 → 비기의 몸이 부풀어 터짐(1번 「터져 죽음」 그대로) → 프랭크가 아트를 체포
13. 경찰차 — 아트 「곧 반장 연락이 올 거야」 → 정말 「대기하라」는 문자, 반장도 위의 명령을 받고 있었음 → 아트: 회사는 알약을 대량으로 만들려 하고 그 원천이 딸 → 프랭크가 아트 편으로(「내 도시야」)
14. 계획 — 딸에게 가려고 아트는 일부러 회사 밴에 잡혀감 → 프랭크와 로빈은 부두의 제네시스호로 따라감
15. 배 — 사진 속 그 여자(박사)가 아트를 맞음: 옛 환자 세포 얘기 = 트레이시도 그렇게 쓰겠다 → 프랭크가 경비를 덮치고 잠입(총 맞아도 방탄), 로빈은 보안실에서 길 안내 → 로빈이 트레이시를 찾아냄
16. 묶인 아트의 딱총새우 얘기(제일 센 동물 = 아트의 능력) → 풀려나 월리스와 싸움 → 트레이시와 재회
17. 탈출 중 로빈이 박사 쪽에 붙잡힘 → 아트 마지막 알약 → 충격파로 박사 일당 끝 → 아트 쓰러짐 → 트레이시의 치유 능력으로 살아남
18. 결말 — 구명보트로 탈출 → 프랭크는 폭로하겠다 → 아트는 딸과 떠나며 로빈에게 트럭(짐칸에 돈 가방) → 로빈은 엄마에게 돈과 약 → 라디오에서 로빈의 첫 싱글
