48 프로젝트 파워: 토막 넷 대본에 검토자 지적을 10번 덧대며 반나절 허비(「아침에 전개 부분 충분히 설명했는데 이게 뭐야. 반나절을 허비하고 있잖아」) → 줄기(사건→왜→그래서, 곁가지 처음부터 뺌)를 먼저 짜서 텔레그램으로 확인받고, 그대로 한 사람이 나레를 통째로 새로 쓴 판에 「전개 좋아」.

**Why:** 덧대기는 새 구멍을 만들고 시간만 쓴다. 줄기가 맞으면 흐름이 처음부터 선다.
**How to apply:** 새 편은 ① 줄기 18줄 안팎(★11-05 사용자 「줄기 확인받기 하지 말고 니가 잘 생각해서 만들어」 — 확인받지 않고 메인이 직접 잘 짬) → ③ 한 사람이 한 번에(다리 줄·누구/뭔지·원인→결과·화자 앞말·화면에 나온 사실만) → ④ 새 검토자 + 사실·그림·잔혹 검사 한 번, 진짜 구멍만 고침(글만 읽는 검토자 숫자 0을 쫓지 않음) → ⑤ 녹음·굽기 → 앞 3분 + 복잡한 구간 미리보기 → 「좋아」 뒤 넘기기. 견본: 저장소 presets/시네플로그/견본/ep48_프로젝트파워_줄기.md, README 「11-05 확정」.
