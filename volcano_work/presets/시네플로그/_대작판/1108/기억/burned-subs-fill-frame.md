원본 영상에 자막이 박혀 있으면 화면을 세로로 꽉 채우고(16:9, 검은 띠 없음) 양옆을 자른다. 자막은 그 조각만 자막 윗줄 위까지 써서 뺀다. 확대(1.2~1.3배)로 덮어 위아래를 자르지 않는다.

**Why:** 10-22 05 다크타워(2.39:1·박힌 자막)에서 사용자 "이거 왜 위 아래가 짤렸어? 쇼츠도 그렇고 왜그래?" → "앞으로 영상에 자막이 있으면 세로로 꽉채우고 양 옆으로 잘라줘".

**How to apply:** build_v9 FILL — ep.json 에 "burn" 이 있으면 자동(끄려면 "fill": false). 쇼츠는 몸통이 꽉 차서 자동으로 칸이 꽉 참(crop.json 다시 계산). 이름표 tag_pos 는 다시 확인. README 「박힌 자막 원본 = 세로 꽉 채우고」.

★10-22 저녁 확장: 06 허큘리스 A판(자막 없는 2.39:1)도 "왜 이것도 잘렸어?" → "이번거는 그냥 두고 다음부터는 풀로 채워서 만들어." — 박힌 자막이 없어도 모든 편 기본 FILL(build_v9 기본값 True). 05·06 A판·06 쇼츠1 은 "fill": false 로 옛 꼴 고정.
