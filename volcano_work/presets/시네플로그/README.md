## ★★★만들기 전에 이것부터 — 둥둥아빠 강의 체크리스트 (10-12 "너 좀 기억하라고 / 둥둥아빠가 말한것들")
1. 박힌 자막은 지우고(확대·크롭) **우리 자막**. 2. 2차 편집: **좌우반전**(대사·글자 컷 제외)·**상하 크롭/확대**·**색조 필터** + 영상만 1.05배속. 3. 원본 3초 이하·3초 건너뛰기, 원본 소리 6초 이하. 4. 나레 1:영상 2, 완성 = 원본 20~30%. 5. 마 뜨지 않게, -16 LUFS. 6. 아웃트로 구조 + **음원 15초**. 7. 정지컷 포인트만, 민감 장면 흑백·블러. 8. 벤치 칼카피라도 1·2번은 반드시.

## 순서
1. 원본(웹하드, 보통 한국어 자막 박힘) → 파일명에 이상한 글자가 있으면 ffmpeg 가 "Illegal byte sequence" — **다운로드 중이 아니다**. python os.link 로 `src.mp4` 하드링크.
2. 소리 10분 토막 → Groq whisper(en) 받아쓰기 → 줄거리 파악.
3. `episode.py` 대본: N(나레, 원본 구간) / D(원본 대사 ≤3초, 한국어 자막). 영화 제목 넣지 않는다. 한국어 약 13,000자 = 1.0배속 ≈ 27분.
4. `tts_all.py` — ElevenLabs eleven_v3 with-timestamps(글자 시각 → 자막 타이밍), 안정성 0.5·유사성 0.71, loudnorm -16.
5. `align_d.py` — 대사마다 앞뒤 15초를 Groq 단어 시각으로 다시 받아써서 정확한 시작·끝(d_final.json). 안 잡히면 박힌 자막 프레임을 0.5초 간격으로 훑어 찾는다.
6. `build.py` — 공정사용 규칙 자동:
   - 나레 구간 원본 컷 ≤2.9초(원본 기준), 1.05배속, 번갈아 좌우반전, 컷 시작은 장면 전환 직후 우선
   - 쓴 구간끼리 원본에서 3초 이상 띄움(대사 구간 포함 전역 검사) → 끝에 "3초 넘는 컷 / 간격 3초 미만" 개수 출력
   - 대사 컷 ≤2.95초, 넘으면 좌우반전 + ≤3.95초
   - 소스 변형: crop=1824:780:48:70(박힌 자막 제거, 5% 확대) → 1920x820 + 위아래 검은 띠 130, eq/hue 색조
   - 소리: 나레 -16 LUFS, 나레 밑 원본 -13dB, 대사 +12dB+리미터
   - 자막: Pretendard Bold 46 흰색·검은 테두리 2.6, 아래 검은 띠 가운데, **무조건 한 줄**(26자 넘으면 나눠서 다음 자막)
   - 위 띠 왼쪽 "CINEFLOG" 만(제목 X)
   - 끝: 마지막 나레 3개 동안 BGM 0.10 → 검은 화면 18초 BGM 0.5 (Kevin MacLeod CC BY 4.0, 설명란 표기)
7. 썸네일 3개(한 줄 큰 글씨·흰+검은 외곽선·노랑/빨강 강조·물음표), 업로드 정보 txt.
