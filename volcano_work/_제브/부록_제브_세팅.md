0. 먼저 지킬 것 (클로드 코드)
- 열쇠(API 키)를 대화 · 파일 · 커밋에 적지 않는다. 환경 변수 TYPESAFE_API_KEY 에서만 읽는다. 있는지 확인할 때도 값은 출력하지 않고 «있다 · 없다»만 말한다.
- 열쇠가 없으면: 사용자의 운영체제(맥 · 윈도우)에 맞는 등록 명령을 열쇠 자리를 비워서 알려 주고, 사용자가 터미널에 직접 붙여 넣게 한다. 열쇠는 https://console.typesafe.ai/keys 에서 발급한다(로그인 · 충전은 사용자가 직접).
- 요청 모양(주소 · 머리말 · 본문)은 기억으로 짜지 않는다. 공식 문서 https://docs.typesafe.ai/api.md 와 2번에서 설치하는 공식 스킬을 먼저 읽고 그대로 따른다.
- 서비스가 거부(429 · 529)를 한 번이라도 돌려주면 전부 멈춘다. 자동으로 다시 보내지 않는다.
- 설치 · 파일 만들기 전에 무엇을 할지 한 줄씩 말하고 진행한다. 끝나면 5번 보고를 한다.

1. 확인
- python3 --version — 3.10 이상(공식 SDK 조건). 아니면 사용자에게 알리고 멈춘다.
- 환경 변수 TYPESAFE_API_KEY 가 있는지(값 출력 금지).

2. 설치
- 공식 스킬 — 사용자가 터미널에서 한 줄씩 실행(설치 뒤 클로드 코드를 새로 켠다):
  claude plugin marketplace add typesafe-ai/skills
  claude plugin install typesafe@typesafe-ai
- 공식 파이썬 SDK: pip install typesafe-sdk — 시스템 파이썬이 설치를 막으면(«externally-managed-environment») 이 폴더에 .venv 를 만들어 거기에 설치하고, 그 뒤로는 .venv 의 파이썬으로 돌린다(사용자에게 그렇게 했다고 알린다). SDK 가 거부(429 · 529)를 자동으로 다시 보내는 기본값이 있으면 끈다(0번 원칙).
- 모델 이름은 jev-1.13.0 으로 고정해서 쓴다(jev-latest 는 새 판이 나오면 답이 달라질 수 있다).

3. 이 폴더에 만들 것
3-1. CLAUDE.md 에 «제브 규칙» 절을 추가 (있으면 합치기) — 이 폴더 CLAUDE.md 에 그대로 넣었다.
3-2. 제브/소재거르기.json — 질문 묶음 본보기 (worth_a_video · is_question · is_complaint · is_noise · kind). noul = 예/아니오(0~1 확률), choice = 보기 고르기, score = 점수. channel_topic 자리에는 사용자의 채널 주제를 넣는다(사용자에게 묻는다).
3-3. 제브/거르기.py — 대량 판정 도구 (사양)
- 실행: python3 제브/거르기.py --spec 제브/소재거르기.json --in 항목.jsonl --out 결과.jsonl
- 항목.jsonl: 한 줄에 JSON 하나, id 칸 필수. 결과.jsonl: {"id": …, "answers": {질문 이름: 답}}.
- 항목 하나 = 요청 하나, 그 항목의 질문은 전부 한 요청에. state 는 이름 붙은 칸(JSON 객체)으로 보낸다.
- 동시 8(공식 한도 초당 80요청 · 10만 토큰 안 — docs.typesafe.ai/models.md). 거부가 나면 전부 멈추고 그 사실을 출력한다.
- 이어하기: --out 에 이미 있는 id 는 건너뛴다.
- 끝나면 건수 · 걸린 시간 · 거부 여부를 한 줄로 출력한다.

4. 시험
- 시험용 제목 3개(사용자 채널 주제에 맞는 것 1 · 광고 문구 1 · 상관없는 것 1)를 항목.jsonl 로 만들어 3-3 을 돌린다.
- worth_a_video 가 주제에 맞는 제목에서 가장 높게 나오는지 확인한다. 아니면 질문 문장을 고치지 말고 결과를 그대로 보고한다.
