## 0. 한 줄

> **"리스크는 선택입니다. 무단횡단부터 안전한 길까지 다 알려드릴 테니, 고르는 건 대표님이 하세요."**
> 완벽할 때까지 기다리면 시작조차 못 한다. **벤치마킹으로 우선 벌고 → 몸에 익히고 → 화이트리스트로 굳힌다.**

- **투트랙**: 벤치마킹·공정사용(빠르지만 리스크) + 화이트리스트(느리지만 안전). 둘을 같이 굴려야 오래 간다.
- 완벽주의 금지. 초보가 남의 퀄리티를 따라가려는 순간 한 달에 하나 → 두 달에 하나 → 포기. "단돈 50만·100만 원이라도 꾸준히 올리면서 발전."
- **수정 요청은 기회.** 배급사·유튜브가 "고쳐 달라" 할 때 바로 고치면 봐준다. "유튜브는 내 사장님."
- 1강에서 손에 쥘 5가지: ① 안 날아가는 채널 세팅 ② 될 영상 고르는 눈 ③ 합법으로 쓰는 법(공정이용) ④ 카피 제작 A–Z ⑤ 정공법 투트랙.

## 1. 채널 세팅 & 애드센스 — 제일 먼저

| 원칙 | 내용 |
|---|---|
| ① 개인계정과 분리 | 비즈니스별로 안 섞기. 개인 / 영화·드라마 채널 / 그 외 각각 |
| ② 1채널 = 1계정 | 채널명과 메일도 맞춤. **무조건 1:1** |
| ③ 번호 1개당 채널 2개 | 1년에 2채널까지 인증. 채널 20개 = 번호 10개 |
| ④ 기기 물리적 분리 | 업로드·관리 기기 분리. 현실적으로 로그인 인증용 폰 |
| ⑤ 2단계 인증 필수 | 15분 넘는 롱폼은 전화번호 인증 필요 |
| ⑥ 애드센스는 저금통 | 명의가 아니라 돈이 꽂히는 통장 기준. 주소는 남의 주소, 통장은 내 사업자 가능 |
| ⑦ 사업자는 신중히 | 사업자로도 애드센스 등록 가능, 혜택 많음 |
| ⑧ 채널 꾸미기 X | "꾸민다고 돈 안 들어옴." 강사는 실버버튼도 신청 안 함 |

- **연좌제 고리 5개**: 복구메일 · 전화번호 · 로그인 기기 · 결제수단 · 접속 IP. 하나가 걸리면 연결 채널 줄줄이 정지.
- 강사는 1기 수강생 채널까지 관리자 계정 하나로 묶어 운영 — "영화·드라마 리뷰만 하면 안 날아간다" 99% 확신. 단 **해외 쇼츠·야담 등 다른 시스템을 병행하면 계정·기기까지 분리**(1기 때 해외 쇼츠와 묶여 날아간 사례).
- **브랜드 계정 필수**(관리자·에디터 권한 이양, 비번 공유 없이 협업).
- **채널 사지 마라**(전 주인이 뭘 했는지 모름).
- 명의가 없으면: 알뜰폰 1인당 최대 3개 추가(월 1,190~1,200원짜리로 충분), 번호 변경은 하루 1회·90일 내 2회, 개인사업자 여러 개 가능, 비상주 사무실(공유오피스)·전대차.
- 주소 인증 = 애드센스 핀번호 우편. 동의받은 주소면 다 됨. 비상주 사무실은 우편을 찍어 전달해 줌.
- **청년창업 소득세 감면**(만 35세, 군필 37세 미만 등): 유튜브는 소득세 100% 감면(지역 요건 있음). 순서: 빠르게 수익창출 → 세무사 선정 → 사업자 등록.
- 3단계 얼굴 인증은 굳이 안 해도 됨. 통장 등록은 수익 조건 채운 뒤.

## 2. 시장 읽기 — 스타벅스 옆 이디야

- **레드오션 = 시장성 검증이 끝났다는 말.** 새 시장을 만들지 말고 이미 있는 시장 옆에 붙어라.
- 정할 것 2가지: **장르**(어느 동네에 가게를 낼까 → 시장 크기·팬층), **주제·컨셉**(그 가게에서 뭘 팔까 → 리스크·조회수·수명).
- **리스크는 주제에서 나오고, 조회수도 주제에서 나온다.** 공포영화 예고편 리뷰 = 리스크 0, 안 팔림 / 결말 포함 스토리텔링 = 리스크 크지만 조회수 잘 나옴.
- **소비 우선순위 공식 = 시간(T=신작) > 국가 > 드라마 > 영화.** 명작도 시간 지나면 화제성 낮고, 망작도 오늘 공개면 오늘 트래픽이 최고.
- 국가: 한국 > 일본·미국·중국 > 제3세계(인도·베트남 등).
- 조합 순위: 신작 한국 드라마 → 신작 한국 영화 → 구작 한국 드라마 → 구작 한국 영화 → 미국·일본 드라마 … → 가장 안전하지만 안 팔리는 건 구작 제3세계 영화.
- **쇼츠는 국가만 작용**(롱폼과 완전히 다름. B급 인도 영화도 쇼츠로는 잘 팔림).
- 기준은 **한국 유튜브 시청자**. 화이트리스트로 만든 걸 해외 수출 X — 화리는 나라마다 권리자가 다름.
- **주제(포맷) 사다리** (위로 갈수록 쉽고, 아래로 갈수록 품이 들지만 오래 감):
  1. 스토리 요약·결말 해석 (가장 쉽고 잘 팔림)
  2. 떡밥·복선 분석 (세계관 조사 필요 — 콘크리트 유토피아·MCU)
  3. 시점 몰아보기 (더 글로리 전재준 시점, 우영우 인물별)
  4. 비교 분석 (그래비티 vs 인터스텔라 — '출발 비디오 여행' 스타일)
  5. 예고편 리뷰 (리스크 최저·수익화 최난)
  6. 리액션 (얼굴 까야 해서 우리는 제외)
- **결정 못 하겠으면**: 롱폼 → **액션 / SF(+판타지·드라마)**, 주제는 **스토리 요약·결말 해석**. 쇼츠 → **그냥 신작**(선물 젬 '신작 데이터 저인망 수집기'로 이번 달 공개작 뽑아 공개 당일 업로드).
- **음악·뮤지컬·애니는 하지 마라.** 음악은 편집이 지옥이라 차라리 화리를 사는 게 나음. 애니는 리스크 대비 실익 없음 — "몇 개월 안에 또 피바람."
- 전망: 롱폼·쇼츠 시장이 극단적으로 양분. 쇼폼은 최소 5년 활성화 → 둘 다 가져가야.

## 3. 될 영상 고르는 눈 — 5기준 + 효율·지속·복제

작품을 고를 땐 반드시 '이유(핑계)'가 있어야 한다.

| 기준 | 체크 포인트 |
|---|---|
| ① 썸네일 적합도 | 한 컷만 봐도 상황이 설명되나? 설명 없이 궁금증 유발? — 작품 완성도보다 **이미지 한 컷의 전달력** |
| ② 트래픽(키워드) | 제목만 봐도 키워드 3개 이상(넷플릭스·평점·신작·결말포함·실화 등)? **서사보다 키워드가 먼저 소비된다** |
| ③ 화제성·극단성 | 잘 만들었거나 **오히려 못 만들었거나**. 논란·충격·불편함? 평가가 극단적으로 갈리나 |
| ④ 플랫폼·제작사 성격 | 경고·저작권이 어려운 대형 메이저인가? **영상이 살아 있어야 수익이 난다** |
| ⑤ 확장성 | 비슷한 작품이 여럿? 합본 가능? — 한 작품 = 한 영상 / 한 주제 = 여러 영상 |

- **"찬양보다 논쟁이 오래 간다."** 시청자는 "와, 소재 미쳤네" 하고 들어와 보고 욕하고 나감 → 그 논쟁이 트래픽.
- 트래픽은 영화 밖에서도 옴(커뮤니티·대형 유튜버 언급, 속편 공개 시 1편 리뷰).
- **결말 포함을 제목에 넣는 이유**: 결말까지 보러 온 시청자가 미포함이면 그 채널을 의도적으로 피함.
- 명작이고 트래픽 좋아도 고소하는 배급사면 — "굳이?" **익절은 항상 옳다.**
- **될 영상 3기준 = 효율·지속·복제**
  - 효율: 반드시 정량화("하루요" X → "몇 시간요"). 강사: 편집만 하면 1시간에 5~6분, 8시간 빡세게 하면 40분짜리. 직원 기준 = 시간당 2분 × 효율 75% = 하루 12분 최소선.
  - 지속: 롱폼은 유행에 안 민감, 꾸준히 팔림.
  - 복제: 결국 공식화가 되느냐. 벤치 대상은 **'어설픈 채널·적당한 난이도'** — 반복해 찍어내며 숙련도 올림.
- 롱폼 시장 크기는 2,000만으로 보고 들어가라(강사가 「수리남」 1,000만 찍을 때 남들은 200~400만).
- 한 편에 목숨 걸지 말고 빠르게 여러 번. 자기만의 마감을 정하라.

## 4. 저작권 — 현업이 실제로 쓰는 건 6개

| 계열 | 항목 | 현실 |
|---|---|---|
| A 허락받기·사오기 | 직접 허가 / 구매·라이선스 / 제휴·협찬 / **묵시적 허락** | 연 없으면 못 함. 묵시적 허락은 우리도 씀 |
| B 권리 제한·만료 | **공정이용** / CC 라이선스(**SCP**) / 퍼블릭도메인 | 회색지대 — 2강의 주 무대 |
| C 내 것으로 만들기 | 직접 제작·촬영 / 스톡 소스 | "가능하시겠어요?" |
| D 보호 대상 아님 | 사실·아이디어(줄거리라는 '사실') | 단, 그걸 담은 '영상'은 보호 대상 |

- 공정이용은 솔직히 우리에게 해당 없음(수익창출). **"아주 좋은 핑계거리"** — 핑계가 통하려면 퀄리티가 진짜여야.
- 배급사도 반신반의하며 인정: "저번 달엔 안 팔렸는데 딱 이 영상 기점으로 팔리네."(왓챠 큐레이터 링크 추적)
- **묵시적 허락 = 러브레터 전략**: 경고 = 반대편 테이블에 앉았다 = 소통 창구. "정말 감동적으로 봤고, 제 영상 한 번만 봐주세요" 식 업무적 제안서 → 실제 수강생 성공 사례.
- **CID를 믿어라**: 경고가 아니라 '침해'면 "이 정도 수정하면 된다는 뜻이네?" 하고 될 때까지 수정해 올림.
- **SCP(크리에이티브 커먼즈)는 영화·드라마에 가장 적합한 무료 카드.** 다만 쓸 영상을 찾는 게 품. (침착맨 채널도 '긴 방송 잘라 요약 = 단순 짜깁기'로 재사용 맞은 뒤 CC 라이선스 구조로 정리한 사례)
- 퍼블릭도메인(사후 70년)은 현실적으로 무의미.
- **지금은 '영화판 춘추전국시대'**: 메가박스(영화 배급 25%+) 회생, JTBC 회생 — 권리 변동기 → 우리 입지가 커짐. 이 시기엔 **OTT 위주 또는 화이트리스트** 강력 추천. 경력자면 넷플만 고집 말고 **아마존·디즈니**로 넓혀라.

## 5. 재사용 항소는 백신 — '롱폼으로 통과'

| 구분 | 누가 때리나 | 무엇이 문제 |
|---|---|---|
| 저작권(CID·경고) | 권리자(배급사) | 원본 저작물 사용 |
| 재사용 | 유튜브 AI | 내 영상에 원본이 너무 많이 → 항소로 풂 |
| 중복도 | 유튜브 업로드 필터 | 다른 사람 것과 많이 겹침 → 2차 편집으로 회피 |

- 롱폼은 재사용 항소 승소율이 매우 높고 쇼츠는 상대적으로 낮음.
- **이상적 플랜: 롱폼으로 수익창출 → 재사용 한 대 맞고 항소 통과(백신) → 쇼츠로 달린다.**
- 절대 규칙 2가지: ① 항소 전 상태 변화 금지 ② 항소 후 항소 영상 절대 삭제 금지(일부공개로 둘 것 — 유튜브가 '인증 표식'으로 봄). "재사용 맞고 영상 안 지웠는데 또 맞았다는 사람, 한 명도 못 봤습니다."
- 항소는 채널 전반을 봄. 롱폼 스크립트 빽빽 + 쇼츠에 나레이션 한두 줄이면 항소 실패.
- 백신 맞았다고 나레이션 빼고 순수 짜깁기로 가면 바로 날아감.
- **쇼츠 방어 = 오디오 위주 편집 + 나레이션 7줄 이상**
  - 실측(현업 쇼츠 3편): 나레이션 10개/효과음 2~3개, 7개/효과음 1개, 59초에 8개.
  - **세는 기준은 문장이 아니라 '내 목소리·효과음·대사가 나온 단위'**("퍽퍽퍽" 효과음도 1개).
  - 재사용으로 날아간 대형 유튜버들은 전부 쇼츠에서 날아감. 롱폼은 날아갈 건덕지가 없음.
- **컷이 3~4초인 이유**: 사람이 한마디 하면 보통 3~4초에 끝남. 배우 호흡까지 살리려는 건 예술병 — **오디오 편집 우선, 호흡 다 날리고 스피드 있게**가 리뷰 시청자 리듬. 그래서 화리 편집점을 잡아주는 클로드 스킬을 만듦.
- **중복도 회피 스킬**: 얼빡(확대) · 미러링(좌우반전) · 색감 변경 · 오디오 추출 · 장면 바꾸기 · 컷 순서 변경. "다 아시잖아요. 아는데 적용을 안 하죠. 이게 진짜 날먹입니다."

## 6. 벤치마킹 = 메타몽 (카피와 다름)

- **카피** = 원본 띄워놓고 나레이션만 교체. **벤치마킹** = 뼈대(스크립트·구성)만 가져오고 살은 내가 붙이는 것.
- 영상 복사가 아니라, 하면서 **자막 넣는 법·순서 바꾸기·음량 조절**을 익혀 롱폼 적응력을 기르는 과정("물에 들어갈 때 가슴에 물 묻히기").
- 강사가 카피당한 사례: 원본 400만 vs 카피 80~90만. 스크립트 그대로, 강사가 고른 컷과 거의 동일 → AI가 "카피 100%" 판정. **그런데 카피본에 저작권이 안 떴다**("유튜브 AI도 그렇게 똑똑하진 않구나"). 강사의 그 영상은 55번째 영상·10회 수정 끝에 살아남아 수천만 원.
- **벤치마킹 주의점 3가지**
  1. **업로드 기준 6개월 지난 영상**을 골라라(저작권 정책이 급변하지 않았고 트래픽은 어느 정도 죽은 시점. 작품 출시가 아니라 벤치 채널 업로드 기준).
  2. **한 채널만 파지 마라**(3일 뒤 똑같이 올라오면 "딱 한 번만 걸려라" 하고 벼름 → 하나씩 아웃).
  3. **완전히 똑같이 하면 저격당함.** "이걸 공부하는 느낌" 정도로.
- **시장 조사는 시크릿 모드로**(내 계정 피드 오염 방지). 시크릿 창에서 장르 검색 → 아무 이력 없는 사람에게 뜨는 채널 확인 → 그 바닥 쭉 구독(경쟁자 확인 + 벤치 대상 확보). 시크릿인데도 반복해서 뜨는 채널 = 유튜브가 "요즘 이거 잘 보더라" 하고 밀어주는 채널.

## 7. 소스는 어디서 — "다운로드까지는 불법이 아닙니다"

- 유통·다운로드·편집까지는 불법이 아니고, **업로드하는 순간부터** 저작권법 영역 → 공정사용을 주장하게 됨(업로더는 세게, 다운로더는 약하게 처벌).

| 소스 | 도구·비용 |
|---|---|
| 유튜브 | 4K 다운로더 / 히토미 다운로더 / 클립다운 — 전부 무료(하루 10개 제한·오류 나면 갈아타기). 유료 6~7만 원 |
| 웹하드 | 충전형 캐시·포인트. 자본금 3억 이상 업체만 가능한 정식 제휴. 최신작·장르·연도별 검색 |
| OTT | Flixicam · FreeGrabApp 등 — 평생 라이선스 약 10~15만 원. 자막도 SMI/SRT/TXT로 |

- **자막은 SRT, 영상은 MP4**(모든 편집 프로그램 호환). MKV는 클로드 코드에 "MP4로 바꿔줘".
- 유튜브에서 받으면 남의 자막·워터마크가 남음 → 깨끗한 소스는 웹하드.
- 넷플 신작 롱폼 전쟁: PST 자정 공개 = 한국 오후 4~5시 → 작가 오후 2~3시 출근해 시놉·예고편으로 뼈대 → 공개 즉시 대본·녹음·편집 → 새벽 1시 업로드. 기업화돼 있음 → **본업 있으면 신작 롱폼은 지우고 쇼츠 신작으로**(쇼츠는 기업 비중이 낮음).
- **단편 무료 창고**: ALTER, Screamfest, ACM, OMELETO, Short of the Week, DUST, Short Films(인도), Adult Swim 등. 편지를 쓰면 회신율 매우 높음(목적이 홍보·발굴). 구독자 0명이어도 됨.

## 8. 실습 A–Z — 벤치마킹 롱폼 (캡컷)

워크플로: **영상 확보 → 스크립트(대본 연금술사) → TTS → 캡컷 편집 → 자막 → 썸네일·제목**

1. **벤치 영상 선정**: 시크릿 모드 장르 검색 → 반복 노출 채널. (실습: 액션 채널 하나, 18분짜리 → 15분으로 줄여 제작)
2. **스크립트**: YouTube Summary로 나레이션 긁어 '대본 연금술사'(3단계 젬)에 넣고 문체 번호만 입력(1 스피디한 쇼폼 / 2 몰입형 스토리텔링 / 3 긴장감 맥스 / 4 극장 톤 — 대부분 1·2). "원본이랑 글자 수 몇 자니?" → 206 vs 204 → "조금 더 압축해 줘" → 177자. **글자 수를 줄이면 컷을 날릴 자리가 생겨 디지털 지문이 훼손됨.** 무료 버전(플래시)으로 충분.
3. **TTS(일레븐랩스)**: 목소리 4종 즉석 비교(기본 보이스 / 클로닝 / v2·v3). 이상하면 버전을 바꿔라. 속도 조절 가능.
4. **캡컷 편집**
   - 우클릭 → **장면 분할**(자동). "캡컷도 AI라 컷 전환을 인식 → 유튜브도 당연히 인식." 그 디지털 지문이 계속 일치하면 재사용.
   - 나레이션 시작점에 맞춰 자르고 → 불필요 구간 삭제 → 앞으로 당기기 반복. 강사 취향: 나레이션이 바뀔 때 장면도 바뀌는 것.
   - **원본 오디오는 -25~-30dB로 낮추기.** 긁을 때 뒤까지 딸려 오니 미리 잘라둘 것.
   - 자막: 캡션 → 한국어 생성 → 클릭·스페이스바·딜리트로 구간 합치고, 클로드 코드가 만든 SRT를 Ctrl+A → 붙여넣기(매크로 마우스/키보드 추천 — 로지텍 G304 2~3만 원).
   - 원본 자막 가리기: 확대(예: 171%) 또는 **위아래 검은 도형(템플릿)**. 아래 도형이 내 자막을 가리지 않게 순서 조정.
   - 워터마크·로고는 자막과 같은 방식으로 덮기("내 시그니처라고 우기면 됨").
5. **2차 편집(중복도 회피)**: 미러링(단축키), 색조 변경, 확대, 위아래 템플릿.
   - **대사 있는 컷은 절대 미러링 금지**("여보"가 "보여"가 됨). 나레이션 구간·대사 없는 구간만.
   - 강사 방식: **한 컷 하고 한 컷 건너뛰기** — AI는 헷갈리게, 시청 흐름은 유지.
   - 미러링·삭제하면 앞뒤로 **한 프레임**이 튐 → 당기고 지워라(시청자가 거슬려함).
- **작업 순서 반드시**: ① 음성(오디오) 배치 → ② 컷 편집 → ③ 2차 편집(미러링·색조·확대·템플릿) → ④ 후작업(자막·로고·꾸미기). 순서 틀리면 전부 다시. "컷 편집만 끝나 있으면 자막 없이 올려도 볼 사람은 봅니다."
- 퀄리티에 매몰되지 마라(뒤에 자막 살짝 보여도 지장 없음 — 시청 만족도는 오르지만 매출엔 큰 변화 없음).
- 벤치마킹의 한계: 확대하면 내 자막까지 잘리고, 자막 많은 채널은 더 지저분. **편집을 할 줄 안다면 스크립트만 참고하고 직접 편집하는 게 더 빠름.**
- ★ **한 번 통과시킨 편집본은 무궁무진하게 재활용**: 길이 줄여 45/40/30/20분, 좌우반전본, 얼빡본, 15분 두 개 합쳐 30분 합본까지.
- 합본 팁: 저작권 걸렸던 게 합본으로 만들면 안 걸리기도(반대도). 명절·연휴는 우리에게 대목.

## 9. 프리미어 프로 — 이 기능은 부럽다

- 메인은 캡컷. 프리미어 장점: 협업 편함(유료는 컴퓨터 2대까지), 채용 시 버전 명시.
- 시퀀스 1920×1080, 정사각형 픽셀, 미리보기 코덱 시네폼.
- **레이블(색상)** 활용이 핵심: 나레이션 구간=1번(노랑), 수정한 컷=2번 → '레이블 그룹 선택' → 오디오 게인 -25, 효과 붙여넣기 등 단체 작업.
- 통합 편집, 이중 프레임 마커(중복 사용 클립 표시), 장면 편집 탐지, 캡션 만들기 → '트랙의 모든 캡션에 스타일 적용'. 가로 뒤집기는 효과 하나 만들어 복사 → 레이블 그룹 선택 → 붙여넣기.
- ★ **캡컷엔 없고 프프에만 있는 = 메타(타임코드) 표시**: 원본 영상의 현재 시간 + 이 클립 길이를 띄워놓고 편집 → 클로드 스킬의 편집점(예: 06:32)을 찾아가고 **지금 몇 초 쓰는지 실시간으로 보며 3초컷을 지킴**. 공정사용에 결정적.
- 캡컷은 컷이 자주 튀고 프프는 덜 튐. 프리미어 줌 특강 별도 예정.

## 10. 화이트리스트 & 채널 공개 — "느려도 돈은 됩니다"

| 종류 | 조건 | 비고 |
|---|---|---|
| [안전] 무료 리스트 | 구독자 0명도 가능 | 단편·웹드 중심. 제작사에 직접 허가받아 작품별 사용 가능 편수(10편 등)까지. 모니터링 없음 |
| [안전] 추천제(무료) | 성과 나온 분을 배급사에 리스트업 | "구독자는 낮은데 트래픽이 기가 막힙니다" 하고 강사가 어필 |
| [조건부] 구매 리스트 | 상업 영화 약 300편 / 6개월 10만 원(편당) | 모니터링함. 카톡방에서 리스트 확인 후 선택 |

- 화리는 배급사가 직접 관리, 문제 시 채널 관리자 권한 위임. 절차: 구매 → 소스 확보 → 작업 → **일부공개 업로드 → 배급사 컨펌 → 전체공개**, 그때부터 6개월.
- 6개월인 이유: 폭발적 트래픽은 6개월이면 다 뽑힘. 연장·교체 가능.
- 한국 메이저 IP(신세계·타짜·관상 등)는 "돈 문제가 아니라 그냥 안 쓰고 싶다" → 외국 작품이 주력.
- 리스트 비공개 이유: 경쟁업체.
- **화리도 CID를 받는다**(미국 라소그룹 등 해외 관리사가 한국 배급사 계약을 모름). 배급사에 연락 → 해결. 요즘 유튜브가 반론통지를 안 받고 "당사자끼리 해결하라"며 발을 빼 시간이 걸림 → "다음 거 해, 다음 거 해."
- ★ **강사 채널 실물 공개**: 전부 롱폼·전부 화이트리스트·편집은 프리랜서만(직원 없음, 클로드 스킬 없이 "화리니까 편집 쉬울 거야, 스크립트도 양식대로 써"). 쓰다 만 채널을 3월에 재활용 → **90일 약 1,700만 원, 영상 37편**. 투자비 화리 37×10만 + TTS 월 10만×3 = 약 400만 → **순익 약 1,300만 / 월 430만, ROI 200~300%**.
- 구독자에 매몰되지 마라(구독자 1,000~2,000명이어도 월 500~1,000만).
- 반대편 사례(리스크 채널): tvN 소재 쇼츠 조회수 2.2억 × 단가 0.15원 ≈ 3,300만 원/5개월 = 월 660만, 영상 167편 × 편집 1만 원 = 167만 투자. "언젠가는 날아갈 채널이지만 올해 3,000만 원 벌겠다면 이렇게도 할 수 있다."
- **리스크는 선택**: [위험] 하이리스크·하이리턴(신작·대형 배급사 정면, 트랙1 최전선) / [조건부] 아슬아슬 선타기(신작+구작 병행) / [안전] 로우리스크·로우리턴(화리만, 트랙2).
- 투트랙이면 **계정 2개**가 베스트(하나 날아가도 안전 트랙 생존). 경고 생기면 몸 낮추고 두 번째 채널 트라이.
- SBS 3아웃 실화(2강과 같음) → 방송사들은 이미 영업을 뛰고 있었다 → 강사도 영업 시작.
- 합의금은 수익에 비례하되 수익을 넘지 않음. 다만 징벌적으로 때리는 곳도 있음.
- **채널이 알려지는 게 다 좋은 건 아니다.** 수익 공개한 순간 신고 열풍. 강사도 채널 노출 뒤 몇 년 멀쩡하던 채널이 저격당함.

## 11. 과제 (1주차) & 수익창출 계산

- 1주차 목표 = **영상을 어떻게든 실제로 만들어 보기**. (선택) 채널 세팅·컨셉 / **(필수) 벤치마킹 영상 1개(롱폼)** / (선택) 보조도구로 쇼츠 1개. 기한 7/19(토) 24시.
- 제출: 구글 드라이브 업로드 → '링크가 있는 모든 사용자'·'뷰어' → 링크 공유 후 릴레이.
- **순수 작업시간 꼭 체크**(편집 시작~끝낸 시각).
- **길이 최소 8분**(미드롤). 롱폼은 길수록 좋다.
- 작품을 정해주지 않는 이유: "투모로우 워 하세요" 하는 순간 140분 중 60~70분이 그걸 함 → 스스로 레드오션을 만듦.
- **수익창출까지의 계산**
  - 롱폼 시청 지속률 20~25%가 정상. 25분 × 20% = 조회 1회당 시청 5분.
  - 4,000시간 = 24만 분 ÷ 5분 = **약 4.8만 조회면 시청시간 충족**(25~30%면 3만대).
  - 쇼츠에선 "망했다" 소리 듣는 숫자 — 롱폼은 금방.
  - 구독자는 롱폼으로 안 모이니 **신작 쇼츠(나레이션 듬뿍)** 로. 강사는 쇼츠→쇼츠→롱폼→쇼츠…로 6일 만에 수창한 적도.
  - 페이스: **3일에 롱폼 1개 + 틈날 때 신작 쇼츠.**
- **한 달 운영비**: 최소 = 캡컷 19,800원 + 일레븐랩스 스타터 $5 + 영상 0 + AI 0 ≈ **월 3만 원**. 업그레이드 = + OTT 다운로더 평생 10~15만(1회) + 클로드 3만 → 월 10만 언더.
- 일레븐랩스 크레딧은 **1글자 = 1크레딧**. 25분 결말포함 스크립트 ≈ 7,853자(공백 포함 8,805자, 5,000자 초과분은 나눠 생성) → 스타터 3만 크레딧이면 월 롱폼 4편(주 1편).

## 12. Q&A 핵심

- **채널·계정**: 1채널·1계정·1번호·1애드센스가 가장 깔끔("월 1~2천 원 아끼려고?"). 채널이 날아가면 그 계정으로 만든 채널 전체가 날아감. 롱폼 PC 업로드여도 폰은 로그인·번호 어뷰징용. 네이버 메일 구글 계정 OK. 이미 수창된 채널을 영화로 바꿔도 됨(아까우니 쓰되 결이 안 맞으면 새 채널). "컴퓨터가 오염돼 새 채널 못 올린다" → 컴퓨터가 아니라 IP 문제, 통신사에 IP 변경 요청. 가족이 다른 장르 쇼츠 하면 불안할 때 회선 하나 더.
- **저작권·CID**: **침해는 100개 받아도 괜찮고, 경고는 3개면 아웃.** 수창 전 영상에 CID 떴는데 채널 영향 없으면 그냥 둠(조회수·구독 채우고 나중에 지움). 애플TV는 넷플보다 낫다(점유율 낮아 잡는 데 소극적 — 점유율 먹는 순간 태도 바뀜). 넷플은 구작 외화는 괜찮지만 쿠팡처럼 배짱 부림 → **아마존·디즈니로 트는 게 낫다**. 50·70년 지난 작품(70년대 흑백 영화)은 하지 마라. 웹하드 안전 기준은 없다. **애니 하지 마라.** **원본 BGM·오디오 통으로 = 오디오도 저작권.** 한 컷 10분 원테이크 장면 그대로 X — 잘라서 구도가 바뀌는 것처럼. **공정사용 3초 룰도 사람이 만든 것 → 본인 기준을 세워라("3초 쓰고 2초 건너뛴다"로 정했으면 지키고, 걸리면 "4초 쉬고 2초"로 바꿈). 기준을 지키면 공정사용은 무조건 된다.**
- **제작·편집**: 강사 편집만 시간당 5~6분, 스크립트·녹음 포함이면 25분 롱폼에 약 4시간("기술이지 지식이 아니다"). 최소 8분, 60분짜리엔 광고 15개(4분에 1개꼴). 나레이션 개수는 대사 전 한 구간을 한 줄로 — 나레·대사·효과음이 오가는 단위로 세서 7개 이상. BGM 교체는 중복도 대책일 뿐(롱폼은 재사용이 문제). 한국 작품 스크립트에 대사가 섞이면 대본 연금술사가 나레이션으로 바꿔 줌. **대본 쓰는 원리는 '받아쓰기'** — 장면을 그대로 받아쓰고("그리고" "쏟아지는 사람들" "28년 전") 시간 정보를 붙인 것 = 클로드 스킬. 영화는 기승전결이 완벽한데 나레이션 넣는 이유 = 수창 조건 충족(앞이든 뒤든 상관없음). 다채널이면 다양한 장르 추천(같은 걸 내꺼내먹은 6개월 뒤 가능). 프로젝트 파일: 채널별 폴더 → 작품별 폴더에 영상·음성·스크립트·자막·썸네일 한곳에, 001 넘버링, 상세 설명에 작가·편집자·검수자·버전. 타입캐스트 vs 11랩스 → 편한 걸(강사는 11랩스 정착). **TTS AI 표기는 강사는 안 함**(해도 무방, 영화 리뷰는 AI 표기보다 재사용이 포인트).
- **항소·수익창출**: 재사용 항소 거절 → 그 영상들 지워도 됨, 재신청 때 유효 조회수 필요하니 계속 올려라. 항소 안 했으면 한 번 해봐라. 수익 정지된 쇼츠 채널 3개월 → 쇼츠는 비공개 말고 삭제, 결 맞으면 롱폼으로 채우고 아니면 새 채널. 400만 영상 삭제 → 이미 발생한 수익은 받음. 한 달 안에 수창하려면 3일에 롱폼 1개로 4,000시간, 구독자는 쇼츠로 — 시간 차면 롱폼 멈추고 쇼츠 전환.
- **화이트리스트·운영**: 화리는 편당. 배급사가 잘 주는 채널·장르는 없다 — 그냥 트래픽이 최고. 화리를 벤치마킹하지 말고 **화리 스킬로 직접 편집**이 더 빠르고 퀄 좋음. 기간이 있는 이유: 배급사끼리 권리 거래·가치 변화. 비수강생은 화리 못 씀. 채널은 한 개부터 제대로. 영화와 상관없는 영상이 있는 채널은 몇 개 없으면 빨리 지우고 갈아타라. **주제를 하나로 모아라**(알고리즘이 디테일해짐 — 예술이 아니라 돈).

## 14. 2강과 맞춰 본 것 (차이·보강)

- **초 규칙**: 1강은 "3초 룰도 사람이 만든 것, 본인 기준(예: 3초 쓰고 2초 건너뛰기)을 세워 지켜라", "한 컷 하고 한 컷 건너뛰기". 2강 실습에서 **"3-3"(3초 쓰고 3초 건너뛰기)** 로 구체화. → 모르면 3-3.
- **벤치 대상**: 1강 = 업로드 6개월 지난 영상, 어설픈 채널·적당한 난이도, 한 채널만 파지 말 것. 2강 피드백 = **구독자 5만 미만** 채널(15만·25만·157만은 잘못 고른 것), 과제 안내 때 "최근 3~4개월 된 것"이라는 말도 나옴 — 수치가 조금 다르니 헷갈리면 사용자에게 확인.
- **원본 오디오**: 1강 = 게인 -25~-30dB로 낮춤. 2강 = 원본 음성은 짧게(6초 이하) + 게인 조절.
- **미러링**: 1강 = 대사 있는 컷은 절대 금지. 2강 피드백 = 미러링 티 나면 안 됨.
- **넷플릭스**: 1강 = 구작 외화 괜찮지만 아마존·디즈니로 넓혀라. 2강 = 외화는 N 오리지널만(아논 제외), 한국 넷플 오리지널 롱폼 불가, 쇼츠는 허용.
- **작업 순서** ① 오디오 배치 → ② 컷 편집 → ③ 2차 편집 → ④ 후작업 — 2강 실습도 같은 순서(나레이션 먼저 깔고 장면을 붙임).
- 공통 숫자: 롱폼 8분 이상, 쇼츠 나레이션 7줄 이상, 나레:원본 1:2, 항소는 롱폼, 채널·계정 1:1, 순수 작업시간 기록, 애니·음악 금지.
