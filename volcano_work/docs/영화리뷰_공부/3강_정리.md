## 0. 3강의 자리

- 1강 = **만들 줄 안다**(벤치마킹으로 버는 법) → 2강 = **걸려도 이긴다**(공정사용·항소·CID 대응 = 맞았을 때 방패) → **3강 = 계속 살아남는다**(애초에 덜 걸리게 만들고, 오래 살아남는 법 = "안 맞게 하는 편집" + "오래 달리는 운영").
- 세 덩어리: **① 손 = 후작업 편집 / ② 머리 = 기술적 사고와 리스크 / ③ 길 = 경쟁자 우회와 크루.**
- **"편집 실력은 어차피 평준화된다.** 컷 튀고 미러링 어색해도 한 달이면 다 비슷해짐. **잘 만드는 사람이 아니라 계속 만들 수 있는 사람이 살아남는다."** 진짜 갈리는 건 ① 후작업 전략(리스크를 지우는 2차 편집) ② 리스크 관리(오래 달리는 운영) — 실력이 아니라 '알고 모르고'의 문제.
- **4대 명제**
  1. 편집은 예술이 아니라 '문제 해결 기술'. 예쁘게가 아니라 안 걸리게.
  2. 잘 나가던 채널이 죽는 이유는 실력 부족이 아니라 '리스크 누적'. 한 번에 안 죽고 조용히 수명이 줄어든다.
  3. 초보는 실력으로 지는 게 아니라 '속도'로 진다. 저위험에서 물량을 쌓는 사람이 이긴다.
  4. 경쟁 분석은 '잘 만든 영상'이 아니라 '리스크를 어떻게 피했는가'를 본다. 안 쓴 장면을 보라.
- 3강이 끝나면 손에 쥘 것: ① 2차 편집 7종 체크리스트 ② 기술적 사고 회로(저작권 = 처벌이 아니라 '수정할 에러') ③ 5대 리스크 자가진단 ④ 경쟁자 분석 새 기준('오래 사는 영상'을 보는 눈) ⑤ 작품 선택 의사결정 트리 + 지오블락·크루.

## 1. [손] 리뷰의 완성은 '후작업' — 2차 편집 7기법

- 컷을 더 잘 친다고 조회수가 늘지 않는다. 심화 편집의 목적은 딱 하나 **리스크 제거**.
- 벤치마킹으로 만들면 원본과 비슷하다는 뜻 → 콘텐츠ID와 사람 눈이 잡는다 → 원본을 '내 것처럼' 바꿔놓는 게 **후작업 = 2차 편집**. (2강: 원본 그대로 = 위험 / 변형 = 안전)
- 전부 캡컷으로 됨(하나 빼고 — 지오블락).

| # | 기법 | 무엇을 피하나 | 리스크/난이도 |
|---|---|---|---|
| ① | 유/무자막 소스 세팅 | 원본 자막 흔적·편집 자유도 | 낮음 |
| ② | 속도 조절(슬로우·배속) | 컷 연속성·재생 구간 매칭 | 낮음 |
| ③ | 스크린샷(정지컷)으로 장면 넘기기 | 연속 재생 구간 | 낮음 |

### ① 소스부터 다르다 — 유자막 vs 무자막
- 편집 시작 전에 **소스를 어떻게 받느냐가 절반**.
- **자막 합본**(영상에 자막이 박힌 파일): 편하지만 미러링·크롭 때 자막이 뒤집히거나 잘려 티가 남.
- **무자막 + 자막파일(SRT) 따로**: 손은 더 가지만 자유롭게 변형(미러링·크롭이 자막에 안 걸림). → **선생님은 무자막 영상 + SRT로 받는다.**
- 웹하드 꿀팁: **파일 하나만 덜렁 있으면 대개 자막 합본.** 영상·자막이 따로 있는 걸 찾아라.
  - 검색하면 파일이 많이 나옴. **A 마크 = 제휴파일**, 나머지 = 비제휴. 제휴파일이어도 (괄호) 안에 mp4 파일 1개뿐이면 자막 합본.
  - 비제휴/제휴 상관없이 **자막과 영상이 따로 있는 파일**(예: srt 0.1MB + mkv 14GB, srt + mp4)을 받아 인코딩 프로그램(킹갓클로드·샤나·어도비 등) 이용.
  - 영상이 mkv면 **자막 없이 mp4로 1번(무자막 파일) + 자막 합쳐서 mp4로 1번(유자막 파일) = 총 2번 인코딩**. 이때 **자막을 다른 글꼴로 바꿔서 특이점**을 줄 수 있음.
- 1기 때는 프리미어로 두 번 인코딩. 지금은 자막 없으면 클로드/캡컷 자동자막으로 뽑음(AI 특강). 다만 클로드도 자막 위치를 파악해 **블러 처리하는 수준이 현재 최선이라 안 예쁨**.
- **캡컷 타임라인 세팅(슬라이드)**: V2 = 유자막, V1 = 무자막, A1 = 영상 원본 음성. 모두 연결 해제 → 오디오 1개(A2) 삭제 → 다시 전체 선택해 연결. (인코딩 시 영화 자막이 기본 세팅돼 있음, 참고해 만들어 저장)
  - 불편한 점: 그룹 설정 X면 컷 삭제 편집이 불편, 복합클립도 해제 시 불편, 컷 분할 시 shift를 매번 눌러야 함.
  - 유자막 버전으로 자막을 변경해 인코딩하고, 자막을 바꾸고 싶은 구간을 확대하거나 무자막 구간으로 교체하는 게 나을 수 있음.
  - **무자막 + 자막 버전으로 스크립트를 편하게 쓰고, 실제 편집은 유자막으로 하는 것이 효과적(미리 미러링해 두는 것도 추천).**

### ② 속도 조절 — 슬로우와 배속은 취향이 아니라 무기
- **슬로우**: 짧은 장면을 늘려 쓰거나 컷이 튀는 구간을 부드럽게(프반 때 슬로우 잘 쓴 분들 칭찬).
- **배속(1.05~1.1)**: 원본과 재생 구간이 살짝 어긋나 매칭을 피함. 티가 거의 안 남. 대사는 대사대로 나오고 불필요한 장면(화자 말고 **청자의 모습**으로 하면 더 자연스러움).
- 캡컷: 클립 선택 → 속도 → 표준에서 속도 조절(클립 길이 조절). **부드러운 슬로우모션** — 부드럽게 하려면 **'광학 흐름'** 옵션(단, 장면 전환부에서 지지직거릴 수 있음). '프레임 혼합'은 생성이 빠름.
- ★ **속도를 바꾸면 음성 길이도 같이 변한다 → 나레이션이랑 안 맞음. 영상만 속도 조절하고 음성은 100% 유지**(프프는 Alt+드래그 / 캡컷은 오디오 분리 후 영상만).
- 단, **2번 빠르게 반복할 바에는 슬로우 한 번이 낫다**(프반 피드백).

### ③ 스크린샷(정지컷)으로 장면 넘기기 — 연속 재생을 끊는다
- 2강의 "장면을 이어서 쓰지 마라(3/3)"를 편집 기술로 실현.
- 캡컷: 우클릭 → 편집 → **프리즈** → 재생바 위치의 한 프레임을 정지 이미지로 고정 삽입(예: 3초). 영상이 흐르다 툭 멈춘 정지컷이 들어감.
- **언제**: 인물 소개·배경 설명처럼 **나레이션이 길어지는 구간**. 정지컷 위에 나레이션을 얹으면 자연스러움(예: 부족 소개 자막 "○○ 부족: …").
- ⚠ **남용 금지** — 많으면 슬라이드쇼처럼 보여 **시청지속시간이 떨어짐.** 포인트에만.
- 궁합 좋은 장르: SF·시대극·전쟁물·정치스릴러·법정물 등. 소스 쪽으로 보면 저작권 만료 구간에 전쟁물·느와르·서부극이 몰려 있어 궁합도 괜찮은 편.

### ④ 좌우반전(미러링) — 가장 쉽고 강력한 픽셀 회피
- 콘텐츠ID는 **픽셀을 비교** → 뒤집으면 픽셀 배열이 달라짐. **제일 쉽고 효과가 큼**(프반 때 "미러링만 했는데 통과" 사례 많음).
- 캡컷: 클립 선택 → 편집 → 미러링(좌우 반전). 프프는 효과 '가로로 뒤집기'.
- ⚠ 주의 3가지: ① **자막 합본이면 자막까지 뒤집혀 거울 글씨** → 무자막+SRT일 때 쓰기(베스트) ② **글자·간판·숫자가 크게 나오는 장면은 뒤집으면 티 남** → 그 컷은 미러링 빼기 ③ **효과를 너무 많이 주면 오히려 벤치 티**("효과 많은 벤치 피하세요").

### ⑤ 상하 크롭 — 원본이 '처음부터 잘린 것처럼'
- 화면 위아래를 잘라냄 → **원본과 프레임 비율이 달라지고**, 위아래 원본 자막·워터마크도 같이 가려짐.
- 두 방법: ① **크롭 효과**(캡컷 편집 → 자르기 / 프프 효과 '자르기') ② **검은 박스**(위아래에 검은 사각형 — 원본 자막 노출·터는 장면 가릴 때).
- 프반의 "확대해서 위아래 그래픽으로 지워주세요"가 바로 이것. ⚠ 너무 많이 자르면 인물이 답답 — **시네마 비율(위아래 살짝)** 정도가 안전.
- 화면비 참고: 1.33(4:3 무성영화) · 1.375 아카데미 · 1.66 유럽 비스타 · 1.78(16:9 HDTV·유튜브) · 1.85 아메리칸 와이드 · 2.35 시네마스코프 · 2.39 스코프(1970~현재) · 2.76 울트라 파나비전 70 · 1.43/1.90 IMAX.
- **실무 관점**
  1. **상하 크롭하면 자막이 같이 죽는다** — 대사가 필요한 장면에서 자막까지 날아가는 게 문제 → 그래서 SRT를 따로 두면 좋음.
  2. ★ **검은 띠를 '덮는' 것과 '자르는' 것은 다르다.** 검은 사각형을 위아래에 올리기만 하면 가운데 픽셀은 원본과 100% 동일 → 프레임 매칭에 그대로 걸림. **실제로 잘라내고 다시 배치**하면 프레임 구성이 바뀌어 회피 효과.
- 프레임 매칭 회피 + 위아래 자막 노출까지 가리는 일석이조 — 특히 **벤치마킹할 때 유용**.
- 영화 원본 비율과 모니터 비율이 달라 원래 위아래(과거엔 양옆)가 검게 나오는 경우가 많음 → **원본 → 확대 → 확대+위아래 크롭** 순서로 보여줌(확대하면 화면이 꽉 차고, 다시 위아래 크롭하면 원래 영화처럼 보이지만 프레임은 다름).

### ⑥ 필터·블러·색조 — 색까지 바꿔 매칭을 지운다
- 색상 픽셀 매칭을 피하는 마지막 레이어. **콘텐츠ID는 색상 값도 비교**.
- ① **색조/필터**: 전체 톤을 살짝 바꿈. **민감 소재(자살·유혈 등)는 흑백 처리로 노딱도 같이 피함.**
- ② **블러(가우시안 흐림)**: 특정 부위나 배경을 흐리게. 노딱 걸릴 부위 가릴 때도.
- 캡컷: 필터 탭 / 조정(밝기·대비·색조) — "일괄로 주세요, 귀찮으니까" → **전체 클립에 한 번에 적용**(조정 → '전체 적용', '사전 설정으로 저장').
  - 조정 예시 값: 온도 25, 색조 -21, 채도 50 → 색조에 따라 화면 느낌이 달라짐.
  - 블러: **약한 블러**. 전체 적용 = 편집효과 → 동영상 효과 → 기본형 → **흐리게**(값 10 정도). 마스크 적용 = 부분 블러할 클립을 복사해 위로 끌어올리기 → 마스크 적용 → 편집효과 → 동영상 효과 → 기본형 → 흐리게.
- ★ **미러링 + 크롭 + 색조 세 개만 겹쳐도 웬만한 배급사는 픽셀 매칭을 피한다.**

### ⑦ 지오블락 (→ 3번 덩어리에서)

### 2차 편집까지 배운 상태의 워크플로 (이대로 하면 안 꼬임)
1. **소스 세팅**: 무자막 영상 + SRT(없으면 AI 자동자막). 자막 쓰기 싫으면 **미러링 + 확대 + 크롭 + 색조 한 상태로 인코딩 1차 → 자막 넣은 상태로 인코딩 2차**(클로드/샤나인코더 등).
2. **변형 3종**: 미러링 → 크롭 → 색조(픽셀·색 매칭 회피). **오디오 등 기타 모든 세팅을 여기서 끝낸다(컷 자르기 전).** 그래야 컷을 자른 뒤 뭘 안 해도 됨.
3. **컷 편집**: 3~4초컷, 장면 이어 쓰지 않기(2강 3/3).
4. **속도·정지컷**: 튀는 구간 슬로우, 나레이션 긴 곳 정지컷.
5. **오디오 정리**: 목소리 보정, 배경음악 믹싱, 잡음 제거.
6. **자막·나레이션 얹기 및 기타 후작업**(효과 등).
7. **아웃트로.**
> (1강의 순서 "오디오 배치 → 컷 편집 → 2차 편집 → 후작업"이 3강에서 "변형을 컷 편집 **전**에 일괄로"로 바뀜 — 매 컷마다 미러링하지 말고 소스 단계에서 한 번에.)

| 콘텐츠ID 픽셀 매칭 | 미러링·크롭·색조·속도 |
| 연속 재생 구간 | 3~4초컷·정지컷·분절 |
| 원본 자막·워터마크 노출 | 무자막 소스·크롭·검은 박스 |
| 오디오 매칭 | 나레이션 위주·게인·6초 언더 |
| 노딱(민감 소재) | 흑백·블러·암전 |
| 권리자 국가 노출 | 지오블락 |

> **가장 걱정하는 콘텐츠 아이디(CID)는 원본 세팅을 통해 대부분 피할 수 있다.**

### [체크] 내 과제 영상에 2차 편집 몇 개 넣었나
- ☑ 무자막 소스로 작업했는가(자막 안 뒤집혔는가)
- ☑ 3~4초컷, 연속 재생 구간 없는가
- ☑ 미러링·크롭·색조 중 **최소 2개** 적용했는가
- ☑ 오디오 레벨 통일했는가(원본 통으로 안 흘렸는가)
- ☑ 아웃트로 + 음원 15초 넣었는가
- "안 알려줬잖아!!! 이제부터 하시면 됩니다!"

### 오디오 조정 미세팁 (프반·1기에서 가장 자주 지적된 "오디오 안 맞아요")
- 원리: **나레이션과 영상 오디오의 기준 레벨을 통일**(평균 **-6dB 근처**).
- 일괄 처리 꿀팁: ① 영상 클립을 **자르기 전에** 대사 파트를 들어보기 → ② 오디오 게인 한 번에 조정(클립 클릭 → 기본 → 볼륨 조절).
- 클립을 자른 뒤(컷편집 뒤) 취향별 세팅:
  - 나레이션만 깔끔하게: 영상 소리 **-35~-50dB**(거의 죽임)
  - 나레이션 뒤 배경음처럼: 영상 소리 **-15~-25dB**(살짝 깔기)
- ⚠ 나레이션 나올 때 원본 소리를 완전히 죽이지 말고 살짝 남기면 흡입감이 더 좋음("아래 살짝 깔아주세요").
- 2강: 영상 잘라놓고 오디오 통으로 흘리면 오디오에서 걸림. 오디오도 6초 조심.

### 아웃트로 — 마지막 15초가 광고 수익을 만든다
- 영상 끝 처리 대충 하면 손해. 마지막을 길게 끌수록 광고가 하나 더 붙음.
- **작품 설명 아웃트로 구조**: ① 작품 개요(감독·배우·연도) → ② 작품이 말하는 바(상징·색감) → ③ 어디서 볼 수 있는지(저작권법상 출처 표기) → ④ 좋댓구알.
- **음원 버티기**: 작품 설명하면서 BGM 깔고, 설명이 다 끝난 뒤엔 **소리 키운 상태로 15~20초 유지** → 시청지속시간 올라감.
- 15~20초 유지 구간은 화면을 **검은색**으로 두고 **유튜브 스튜디오 → 콘텐츠 → 편집기 → 최종화면**에서 꾸미기. 최종화면 → 템플릿 적용 → **동영상·구독·동영상 순서가 무난**. 동영상 선택 시 **'시청자 맞춤' X**, **특정 동영상(내가 밀고 싶은 영상)과 최근 업로드된 동영상**으로 선택.
- 광고는 미드롤 광고 슬롯에서 추가 삽입. **3분 30초~4분에 1개씩.** 8분 미만 = 광고 2개, 8~10분 = 3개, 12분이면 4개. **롱폼은 길면 길수록 좋다.**

## 2. [머리] 기술적 사고와 5대 리스크

### 편집은 예술이 아니라 '문제 해결 기술'
- 편집하다 보면 자꾸 예술을 하려 함("이 컷이 더 예뻐야 하는데…"). 우리는 **기술적으로 편집해서 올리는 게 목적**. **"예술 X, 돈 O. 영상 삭제만 안 당하면 됨."**
- 감각에만 의존하는 편집은 오래 못 감 — 감각은 사람마다 다르고 재현이 안 됨. 기술적으로 본다 = 문제가 생기면 '재능·운' 탓 대신 **구조에서 원인을 찾아 변수를 고친다**.

### ★ 저작권은 '처벌'이 아니라 '수정할 에러'
- 실패가 쌓이면 **'내 채널만의 공정사용 리스트'**가 된다. 영화리뷰는 한 방 콘텐츠가 아님 — 이번 영상은 실패가 아니라 다음 영상을 위한 데이터.
- **올릴 때마다 기록**: 어떤 영화가 OK/NG · 어떤 편집이 통과 · 어떤 배급사가 위험 → 남의 카더라가 아니라 내 리스트(2강 테스트 채널과 같은 원리). "이번엔 망한 게 아니라, 데이터가 나왔다."
- 💡 이 리스트가 나중에 **직원·프리랜서에게 넘길 금지 규칙**이 된다.
- CID가 뜨면 대부분 "유튜브가 나를 싫어하나… 저작권이 너무 빡세…" → 비기술적 사고. 기술적으로 CID는 **'고쳐야 할 에러 로그'**.
- 파이프라인으로 보기: 입력(영화 장면 + 스크립트) → **처리(편집·음성·장면 배치)** → 출력(업로드). 문제가 생기면 "이 파이프라인의 **어느 지점**에서 오류가 났는가?"(대부분 **선정/편집**).
- 원인 후보 분리: **장면 길이? 연속성? 음성 트랙? 배급사 특성?** → 변수를 하나씩 수정. 감정이 아니라 **현상 → 구조 → 변수**로.
- "저작권은 벌이 아니라 수정 포인트다." 이 문장 하나만 가져가도 됨.
- 클레임(claim): 콘텐츠ID 자동 / 수익만 제한(채널 무사) / 이의제기·수정. 경고(strike): 권리자 수동(DMCA) / 채널 경고 1회(3회=삭제) / 카운터노티스.
- **CID 걸렸을 때**: 공개 도달범위에 이상이 없다면(**대한민국 공개 가능하다면**) **수창 채널 개설용**으로 쓰면 됨.
  - **통으로 걸릴 때**(재생바 전체가 CID): 오히려 **빠른 쇼츠 전환**이 답(기본적으로 2차 편집·소스 세팅 이후 편집했다는 가정).
  - **일부만 걸렸을 때**: 빠른 수정 후 업로드. 작품에 따라(길이·화제성 등) **3~5회 정도 수정해 보고 재활용**. 영상이 40분이면 30%인 **대략 28분대까지는 수정해 보고 결정**.

### 포기(❌) 대신 변수 수정(✅) — 트러블슈팅 체크리스트

| 변수 | 지금 | 수정 |
|---|---|---|
| 장면 길이 | 5초 | 3초 이하로 |
| 장면 연속성 | 이어 쓰기 | 분절(정지컷·나레이션 삽입) |
| 원본 음성 | 살림 | 더빙(나레이션) 100%로 |
| 화면 | 원본 | 미러링·크롭·색조 |
| 배급사 | 위험 | 제외 리스트에 등록 |
| 구조 | 시각 중심 | 음성(오디오) 중심으로 |

### ★ 망하는 채널은 한 번에 안 망한다 — 조용히 수명이 줄어든다
- 그 수명을 갉아먹는 5대 리스크: **① 저작권 누적 ② 노딱 반복 ③ 감정 소모형 루틴 ④ 작품 소진 ⑤ 조회수 멘탈 의존.**
- 앞의 둘(①②)은 아는 것. **채널을 진짜 죽이는 건 뒤의 셋(③④⑤)** — 실력이 아니라 **지속성 문제**.

**리스크 ① 저작권 누적 — 만료일을 캘린더에**
- 경고는 누적형(3회면 채널 삭제, 하나는 90일 후 소멸).
- ① 경고 1개 상태면 그 배급사는 당분간 안 건드린다(수그리기) ② 만료일을 캘린더에(90일 지나면 2아웃→1아웃) ③ 안전 트랙(화이트리스트·검증 소스)으로만 업로드 유지. → **"누적을 관리하는 습관"**.

**리스크 ② 노딱 반복 — 15세 톤을 '기본값'으로**
- 노딱이 반복되면 광고 수익 구조가 서서히 무너짐. 매번 판단하지 말고 **'15세 톤'을 채널 기본값으로 고정**. 아슬한 장면은 **암전·흑백·블러**, 민감 소재는 아예 안 건드리기(혹은 과감하게 각오).
- 편집 기법이 노딱 방어로도 쓰임: **미러링은 CID용, 흑백·블러는 노딱용.**

**리스크 ③ 감정 소모형 루틴 — 채널보다 내가 먼저 지친다**
- 진짜 무서운 리스크. 콘텐츠를 만드는 게 아니라 감정을 계속 빨아먹히는 구조: "이건 내가 꼭 말해야 해" / "이 장면은 내가 대신 분노해줘야 해" / "이 퀄리티는 용납 못 해" → 다음 영상 생각만 해도 피곤, **댓글 하나에 기분이 요동** → 실력과 무관하게 지속이 안 됨.
- 의지가 아니라 구조 문제. 관리법: **예술이 아니라 기술적으로 올리는 게 목적**이라고 계속 되뇌기, 감정을 싣지 말고 **프로세스로 돌리기**. TTS도 "평평해도 괜찮다" — **완벽주의 내려놓기**.
- **"유튜브는 감정이 강한 사람이 아니라, 감정을 덜 쓰는 사람이 오래 갑니다."**

**리스크 ④ 작품 소진 속도 — 연료를 한꺼번에 태우지 마세요**
- 초반엔 화제작·충격작·조회수 잘 나오는 소재부터 씀 → 성장 빠름, 연료를 한꺼번에 태움. 중반엔 "이제 뭐 하지?" / 소재 급 하락 / 손 안 가는 작품만 남음 / 조회수 서서히 하락.
- 이때 하면 안 되는 실수: **자극 수위↑, 제목 과장↑, 리스크 높은 작품으로 도피**(그래서 채널이 날아감).
- 관리법: ① 화이트리스트를 아껴 **섞어 쓰기**(소재 고갈 0의 안전 연료) ② 좋은 작품을 한 번에 다 안 쓰고 **배분** ③ **구작·마이너 작품 발굴 루틴**(KOBIS·배급사 필모, 2강).
- 💡 **소재가 마르면 채널이 마른다.** 연료 관리 = 채널 수명 관리.
- 특히 혼자 운영하면 **롱폼 + 숏폼을 유지하면서 롱폼으로 수익을 조정** → 수익(조회수 수익)과 성장(구독자)을 동시에.

**리스크 ⑤ 조회수 멘탈 의존 — 조회수는 '판단'이 아니라 '기록'**
- 업로드하고 실시간 새로고침, 새벽까지 통계 페이지(선생님도 그랬음). 문제는 **성과를 '내 가치'와 연결**하는 것 → 방향을 너무 자주 바꿈 → "실력은 쌓이는데 방향은 계속 흔들리는 채널". 분석하지 말라는 게 아니라 **"분석만" 하고 편집을 안 하는 게 문제**.
- 관리법: 조회수는 판단 기준이 아니라 **기록 데이터**. **알고리즘 반응은 지연된다** — 즉각 반응으로 판단하면 매번 리셋. **컨셉 잡았으면 우직하게 밀기.** 데이터는 모아서 주기적으로 보고, **그 사이엔 그냥 만드세요. 제발 제발.**
- 업로드 텀 질문이 많음 → **벤치 채널을 vidIQ로 보라**(예시: 7일 조회 +903만, 구독 124만, 평균 영상 12분, **주 ~16회 업로드**).

**결론: 열정이 아니라 '소모가 적은' 채널이 오래 간다**
- "잘 되는 채널은 열정이 많은 게 아니라, 소모가 적습니다." **리스크 소모·감정 소모·소스 소모·노동 소모**를 덜 쓰는 사람이 오래 감. 오늘 편집 기법도 기술적 사고도 결국 '소모를 줄이는 것'.
- "마라톤이라고 생각하세요. 빨리 달리는 게 아니라, 안 멈추는 게 이기는 겁니다."

## 3. [길] 경쟁자 우회와 크루

### 상위 유튜버를 따라 하면 왜 늦어지나
- "저 사람도 하니까 나도 되겠지" — 조건이 다름.
  - 상위 유튜버: 신고 1~2번 맞아도 채널 안 죽음 / 조회수 변동에 멘탈 안 흔들림 / 알고리즘이 신뢰하는 계정.
  - 초보: 신고 1번 = 치명타 / 노딱 몇 번 = 수익 구조 붕괴 / 조회수 하락 = 방향 전면 수정.
- 같은 행동을 해도 버틸 체력이 다름. 상위 유튜버가 고위험 작품을 해도 사는 건 **잘해서가 아니라 버틸 수 있어서**.
- **"상위 유튜버는 정답이 아니라, 이미 끝난 결과물이에요. 따라갈 대상이 아니라 참고할 대상."**

### ★ 초보가 봐야 할 건 '퀄리티'가 아니다 — 안 쓴 장면을 보세요
- "화려함"이 아니라 **"리스크 설계의 흔적"**을 보는 눈.
- 대부분 초보가 보는 것: 편집이 얼마나 화려한가 / 썸네일이 얼마나 자극적인가 / 컷 전환이 얼마나 빠른가 → 전부 결과물의 표면.
- 봐야 할 것: **어떤 장면을 '안' 썼는가 / 어디서 위험한 표현을 피해갔는가 / 왜 이 장면은 길게, 저 장면은 짧게 썼는가 / 어느 구간에서 톤을 낮췄는가.**
- **6개월 이상 살아남은 채널**을 보라. 그 채널이 '안 한 것'이 곧 내 안전 매뉴얼.
- "이 작품, 엄청나게 재미있는데 **왜?! 안 했을까? 이유가 있을까?** 화이트리스트일까? 편집이 빡센 걸까? 광고나 허가를 받은 걸까? 뭐지?!"

### 왜 구독자가 적은 벤치마킹 채널을 찾으라고 할까
- 조회수·구독자 비교가 아니라 **'지속 가능성'**을 보자.
  - 기존 분석: "조회수 몇? 구독자 몇? 편집 퀄은? → 그래서 이길 수 있다!"
  - 바뀐 분석: **"이 채널은 계속 올릴 수 있는가? 문제없이 운영되는가?"** → 그다음 기존 분석으로 넘어가서 "해당 장르에서 내가 저 사람을 이길 수 있는가?"
- 구체적으로: 업로드 주기가 끊겼는가 / 비슷한 포맷을 몇 편이나 반복했는가 / 논란·신고 날 소재를 어떻게 처리했는가 / 위험한 장면을 어떻게 완충했는가.
- "왜 이 사람은 자꾸 '넷플릭스 작품' / '디즈니 작품' / '아마존 작품'을 하는 걸까? 그 중에서도 왜 액션/SF/공포 등을 할까?"
- 벤치하려는 **장르의 채널 그 바닥을 전부 구독했다면 모니터링**하라 — 알고리즘 때문이 아니라 **내 피드를 바꾸는 이유**가 그것.
- **벤치 채널 4개 질문** (지금 벤치 중인 채널을 다시 보라):
  - ☑ 이 채널, **6개월 이상 꾸준히** 올리고 있나(지속성)
  - ☑ 비슷한 포맷을 **몇 편이나 반복**했나(재현 가능한가)
  - ☑ 위험한 장면을 어떻게 완충했나(**안 쓴 장면 찾기**)
  - ☑ **5만 이하 · 안전 배급사**인가(롱폼 기준으로 판정)

### MCN·지오블락 + 크루
- MCN은 '소속사'가 아니라 **'기능 도구'**: ① **지오블락 기능**(개인 채널보다 국가별 공개 제어가 세밀) ② 광고 단가·정산(일부 MCN은 광고 옵션 유리) ③ 분쟁 대응 지원(저작권 이슈 때 창구).
  - ⚠ 수익 수수료를 떼감(계약 조건 확인) / 계약 기간·해지 조건 꼭 보기 / 아무 데나 말고 **영화·드라마 리뷰를 이해하는 곳**으로.
  - 💡 처음부터 필수는 아님. **수익이 나기 시작하고 지오블락·분쟁 대응이 필요해질 때** 고려.
- **지오블락**: 업로드 → 권리 관리 → 소유권 '전 세계 / 특정 지역', 저작물 정보(저작물 유형 '웹', 제목 등).
  - 핵심: 특정 국가에만 공개하고 나머지는 차단. **우리가 쓰는 법 = 한국에만 공개, 나머지 국가는 차단.**
  - 왜? **대부분의 권리자(배급사)는 해외 본사** → 해외에서 내 영상이 안 보이면 권리자가 발견할 확률이 확 줄어듦. 사실상 **내가 스스로 소유권 주장을 걸어두는 것**과 비슷한 효과.
  - 💡 실제로 대박 영상도 시청자의 90%가 한국 — **해외 7%를 포기하고 안전을 사는 것**.
  - ⚠ 단점: 해외 트래픽 포기. 개인 채널에선 기능이 제한적이라 **MCN이 필요**.
- **그래서 우리는 크루**: 이 방, 이 기수, 이 강의가 곧 크루. 혼자 하면 **정보가 안 돌아서 늦어짐**. 같이 하면:
  1. 정보 파이프라인: "어디 배급사가 요즘 빡세대요" / "이 채널 삭제하고 있대요" → 리스크를 미리 피함
  2. 리스크 공동 대응: **삭제·경고가 돌면 크루가 같이 움직임**(2강 익명 대응)
  3. 소스·광고 연결: 화이트리스트·신작 소스, 광고 **기회를 함께 나눔**
  4. 멘탈: 조회수에 흔들릴 때(리스크⑤) **서로 잡아줌**
- **"저작권을 피하는 능력이 아니라, 저작권 환경에 적응하는 능력."** 그 적응은 혼자보다 같이가 빠름.

### 지속 가능한 채널 성장의 핵심 전략 (한 장 요약)
- **[손] 편집 심화**: 원본 영상 → 미러링·크롭·색조·정지컷·오디오 → "원본을 '내 것'으로. 변형은 항상 옳다."
- **[머리] 기술적 사고 + 5대 리스크**: 저작권·노딱 반복·감정 소모·작품 소진·의존.
- **[길] 경쟁자 우회**: 지오블락·크루 활용.
- **결론: 잘 만드는 사람이 아니라, 계속 만들 수 있는 사람이 살아남습니다.**

## 5. 1·2강과 맞춰 본 것

- **벤치 채널 기준이 정리됨**: 3강 = **5만 이하 · 안전 배급사 · 6개월 이상 꾸준히 · 비슷한 포맷 반복 · 위험 장면 완충**. (2강 피드백 "5만 미만"과 같음. 1강의 "업로드 6개월 지난 영상"은 '영상' 기준, 3강 "6개월 이상 꾸준히"는 '채널' 기준.)
- **작업 순서 업데이트**: 1강 "오디오 배치 → 컷 → 2차 편집 → 후작업" → 3강 "**소스 세팅 → 변형 3종(컷 전에 일괄) → 컷 → 속도·정지컷 → 오디오 → 자막·나레 → 아웃트로**".
- **오디오 수치**: 1강 원본 -25~-30dB / 3강 기준 레벨 평균 -6dB로 통일, 컷 뒤 영상 소리 **-35~-50dB(나레만) 또는 -15~-25dB(살짝 깔기)**, 완전히 죽이진 말 것.
- **아웃트로**: 2강 "개요 → 주제 → 어디서 → 추천 → 좋구알 → 음원 10~20초" / 3강 "개요(감독·배우·연도) → 말하는 바(상징·색감) → 어디서(출처) → 좋댓구알 → 소리 키워 15~20초, 검은 화면 + 최종화면(동영상·구독·동영상)".
- **광고 수**: 2강 "4~5분에 1개" / 3강 "3분 30초~4분에 1개(8분 미만 2개, 8~10분 3개, 12분 4개)".
- **미러링**: 1강 "대사 컷 금지" + 3강 "자막 합본이면 거울 글씨, 글자·간판 장면 제외, 과한 효과는 벤치 티" → 무자막+SRT 소스면 소스 단계에서 한 번에.
- **CID 대응**: 2강 "차단이면 쇼츠로" + 3강 "통으로 걸리면 빠른 쇼츠 전환, 일부면 3~5회 수정(원본 30% 길이까지)".
- **지오블락**: 2강에서 "3강 때" 한다고 한 것 — 한국만 공개, MCN 필요.

## 6. 우리 작업(볼케이노·ffmpeg 제작)에 옮길 수 있는 것 — 후보

적용은 사용자 확인 뒤.
1. 소스 단계에서 **미러링(대사·글자 컷 제외) + 살짝 확대 후 위아래 실제 크롭(검은 띠 얹기만은 X) + 색조 소폭 변경**을 한 번에 인코딩.
2. 영상 **배속 1.05~1.1**(음성은 그대로 두고 영상만), 튀는 곳은 슬로우.
3. 나레이션 긴 구간은 **정지컷(프리즈)** 위에 얹기 — 남용 금지.
4. 오디오: 나레·원본 기준 -6dB 근처 통일, 나레 중 원본은 -15~-25dB로 살짝.
5. 민감 장면은 흑백·블러·암전.
6. 끝: 작품 개요 → 말하는 바 → 시청처 → 좋댓구알 → 음원 15~20초(검은 화면).
7. 업로드 때마다 **작품·배급사·편집법·CID 결과를 기록**해 '내 채널 공정사용 리스트'로 쌓기.
