## 0. 한 줄

> **"대표님은 손을 떼는 게 아니라 최종 감독자로 승진하는 겁니다."** 만드는 사람이 아니라 시스템을 설계하는 사람이 이긴다.

- 1강 = 만들 줄 아는 법 / 2강 = 걸렸을 때 이기는 법 / 3강 = 오래 살아남는 법 / **4강 = 내가 안 만들어도 굴러가게 하는 법.**
- 순서: 3주차 과제 실시간 피드백(1시간 40분) → 화이트리스트 운영 변경 → 본강의(시스템화·채용·작업관리) → 오디오·컷 실습 → 소재 발굴·지표 분석 → 55일 챌린지 → 수강생 채널 실시간 진단 + 끝장 Q&A(3시간).
- 본강 3덩어리: **시스템**(무엇을 넘길까) → **사람**(어디서 얼마에 어떻게 검증) → **지표**(무엇을 보고 언제 고칠까).
- "대표가 병목이 아닌 순간부터 폭발적으로 커진다." 편집이 가장 오래 걸리는 공정인데 대표가 편집까지 하면 **대표 체력 = 채널 성장 속도** → 편집부터 넘긴다. (최소인자의 법칙: 스크립트를 AI로 열 배 빨리 뽑아도 편집이 막히면 채널 속도는 편집 속도.)

## 1. 과제 피드백에서 반복된 지적

### 썸네일 — 거의 전부 '글자 크기'
1. **글자가 작다**: 편집할 땐 큰 모니터라 적당해 보이지만 시청자는 모바일. **화면을 가로로 3등분(길면 4등분)해서 그 폭을 꽉 채우는 느낌**으로. 자간 최대한 좁히고 띄어쓰기를 빼서라도 키움.
2. **두 줄보다 한 줄이 크게**: 강사 기준으론 한 줄 크게가 더 잘 띔. 다만 두 줄이 본인 스타일이면 그대로 — 썸네일·스크립트는 대표 특성이 가장 강한 영역, 지표만 괜찮으면 정답.
3. **앵커를 하나 박아라**: 인물도 글씨도 오밀조밀하면 시선이 어디 갈지 모름. 메인 인물 하나를 확대해 확실히. 배우로 어필할 거면 **그 배우의 얼빡샷**.
4. **글자는 살짝 아래로**: 가운데보다 조금 아래. 인물 설명 넣을 때만 위쪽. **흰 글자 + 검은 획(외곽선)**만으로 충분 — 획을 빠뜨린 분이 많았음.
5. **스케일 업만이라도**: 원본 그대로 쓰면 흐림. AI에게 **"아무것도 건드리지 말고 해상도만 올려줘"** 한 번이면 훨씬 예쁨(수작업이면 선명 효과 도구로 얼굴·눈·턱·수염 라인만 한 땀씩).
6. **느낌표가 아니라 물음표**: "충격의 전말"처럼 결과를 적으면 안 궁금함 → 궁금증 유발 문구로. 극단적으로 "졸라 재밌습니다"는 내용이 없는데도 클릭.
- **색은 노랑·빨강**(가장 잘 띔), 민트는 안 씀(좋아하면 써도 됨). **AI 썸네일 써도 됨**(모바일에선 "선명하네" 하고 넘어감) — 너무 반들반들하면 "시네마틱하게, 실사 느낌으로" 요청.

### 쇼츠 — 대부분 오디오와 호흡 문제
1. **마(공백)를 없애라**: 나레이션 끝나면 바로 대사, 대사 끝나면 바로 나레이션. 1.5초씩 뜨는 공백이 반복되면 루즈. = 오디오 위주 편집.
2. **대사는 살리거나 죽이거나**: 어중간하게 잘라 끊으면 "편집 못하네". 공정 사용이 걱정되면 **일단 살려 올리고 CID 걸리면 그때 수정**이 퀄리티상 낫다.
3. **길이를 조금 더 늘려라**: 30초는 짧음. 쇼츠는 나레이션 넣을 여유가 타이트 → 길이를 늘려 **나레이션 비율을 올리는 게 재사용 리스크를 줄임**.
4. **제목을 화면에 박아라**: 요즘은 제목이 없으면 "채널 관심 없음" 누르고 넘어감. 설명란엔 아무도 안 봄. 저작권법상 **출처 표기**도 원래 해야 함.
5. **나레이션 자막과 영상 자막을 다르게**: 같은 문구로 겹치면 지저분. 겹치는 원본 자막은 지우거나 블러.
6. **벤치 티를 내지 마라**: 비슷한 장면에서 컷만 계속 바뀌면 벤치 티. 한 컷으로 갈 수 있으면 한 컷으로.
- 수위: 식인 장면이 그대로 나온 쇼츠 → 신고 가능하니 **흑백·모자이크·블러**. TTS 한계("안나 에게"→"안내" 붙여 읽기)는 어쩔 수 없음, 시청자도 이해. **드립은 설명하는 순간 망한다.**

## 2. 화이트리스트 운영 변경 (최대 공지)

- 강사 화리 채널도 **두 개 중 하나꼴로 CID** → 매번 이의제기로 풀지만 "화리도 3초 컷이면 공정사용과 차이가 없다"는 불만 → 배급사·관리 측과 협의해 두 가지 받아냄:
  1. **길게 써도 된다**: 화리는 컷을 길게. CID 확률은 올라가지만 걸리면 운영 측에 말하면 **제작사 서류로 이의제기·반론통지를 대신 진행**. 기다리면 됨.
  2. **채널이 터져도 계약 기간은 살린다**: 화리는 작품 하나 기준으로 기간(8/1 업로드면 이듬해 1월까지). 경고 누적으로 채널이 터질 위기면 그 화리 영상을 내리고 **남은 기간 동안 다른 채널에 올려 쓸 수 있게**(AS).
- **단, 바로 올리면 안 됨** — 내리자마자 다른 채널에 올리면 재사용. **최소 2주(15일) 묵혔다가** 하나씩. 결국 2주가 날아가니 경고가 생긴 순간부터 리스크 관리가 낫다.
- 병행 전략: 경고가 있을 땐 화리로만 운영하거나, 화리로 찍어내면서 이의제기가 풀린 영상부터 순서대로 공개.
- 영업 현황: 무료 화리는 셀프 수급이 대부분 가능 → 지금은 **유료·프리미엄 화리 위주**. 초대형 배급사와 **숏폼부터 협업**하는 방향. 유료 화리 할인은 기수 끝나도 유효.
- **넷플릭스는 화이트리스트를 주지 않는다.** "넷플 화리 받았다"는 대개 이의제기를 넣었는데 권리자가 반응 안 해 유튜브가 풀어준 것 — **외화는 이 방식이 통하지만 한국 작품은 다름**(며칠에서 한두 달 안에 경고로 바뀌어 돌아올 수 있음). 넷플 하려면 **한국 작품 말고 구작 외화**. 이의제기로 풀린 영상은 권리 증명이 끝난 것이라 문제없음.
- 화리를 받으면 대개 **대놓고 "화이트리스트"라고 언급**. "저작권 사용 허가를 받아 제작한 자발적 홍보 영상입니다" 같은 애매한 문구는 의심스럽다.

## 3. 대표가 되는 법 — 시스템·사람·지표

- 목적: 대표가 멈췄을 때(아프거나 여행·본업이 바빠도) **업로드가 끊기고 알고리즘이 식는 것**을 막는 것.
- 놀라운 사실: **영상이 100개쯤 쌓이면 아무것도 안 해도 월 150~200만 원**이 꾸준히. 강사가 방치한 채널 하나는 영상 20개도 안 되는데 적을 때 30~40만, 잘 나올 때 100만 원 → 5개 곱하면 감이 옴.
- 3요소: **시스템**(반복을 없앤다) → **사람**(부품이 사람일 뿐, 설계는 대표) → **지표**(관리·감독만).
- 착각 금지: "프리 썼으니까, 직원 뽑았으니까" 하고 던지면 방치. **대표는 설계를 하는 것.**
- 다각화: 시스템이 완성되면 팀장을 세워 다른 장르(공포 → SCP)로 채널을 늘리고, 다른 사업으로 확장.
- 영화·드라마만의 얘기가 아님: 검증된 걸 벤치해 빠르게 만들고, 누가 날아가고 안 날아가는지 비교해 리스크를 판정하고, 노하우가 쌓이면 자동화, 못하는 건 사람, 나온 지표로 내 기준 — 실버 롱폼이든 어떤 바닥이든 적용.

### 무엇을 넘기고 무엇을 남기나
- 반복 공정: 작품 찾기 → 스크립트 → 자막 → TTS → 컷 편집 → 썸네일 → 업로드.

| 역할 | 하는 일 |
|---|---|
| 작가 | 채널 느낌을 아니까 **작품 선정까지 직접**. 스크립트를 써서 팀장 검수를 받거나 지정 편집자에게 바로 넘김 |
| 편집자 | TTS 뽑고, 컷 편집과 자막까지. 끝나면 팀장에게 |
| 팀장 | 썸네일 제작, 영상 검토, 썸네일 체크, 업로드까지 |
| 대표 | 작품·장르 방향 설정, 최종 판단, 지표 관리. **그게 전부** |

- AI가 이미 하는 것: 스크립트(클로드 스킬), 자막(캡컷 자동), 썸네일 스케일 업. 클로드 스킬 도입 후 **하루 2편 쓰던 작가가 4~5편**.
- 아직 사람이 필요한 것: 주로 **편집**. 최종 판단은 대표. 작가는 선택 — 톤을 살리려면 고용, 양산형이면 AI로 충분.
- 클로드 스크립트가 이상할 때("계속 ~합니다로만 끝나요", "마지막에 나레이션이 몰려요"): 학습시킨 원본 스크립트 구조를 그대로 따라간 결과. 클로드는 학습 대본을 구조적으로 분석해(대사 몇 개, 나레이션 몇 개, 문체) 그 틀대로 뽑음. 해결책은 매번 휴먼 터치가 아니라 **"내가 이렇게 고쳤어"를 다시 학습시켜 스킬을 갱신**. 컨텍스트가 차면 "인계 메시지 작성해 줘"로 뽑아 새 대화 첫 줄에 붙여넣기.

### 사람 쓰기 — 어디서, 얼마에, 어떻게 검증
- 어디서: 크몽·숨고에 **내 공고를 띄워 들어오는 사람을 테스트**. 편집몬은 전문 편집자들이 단가를 논의하는 분위기라 낮게 부르면 반발. 정직원은 사람인·잡코리아·알바천국.
- 단가: 공정 사용 편집 **분당 7,500원이 미니멈, 8,000원까지**(20분 영상 15만 원선). 화리는 단가가 더 내려가고 CID 통과가 요청 사항에 안 들어감.
- **건당 계약이 기본**(월급제면 출퇴근·작업 감독 등 노동법 영역).
- 포트폴리오만 믿지 마라(허위 이력서). 영화·드라마 리뷰 포트폴리오 없으면 일단 제외. "팔다리를 구하는 것이지 제자를 구하는 게 아닙니다."
- 실무 과제 전형: 서류 합격자에게 일주일 기한 실제 작업. **합격 여부와 무관하게 실무비 3만 원 지급**(공짜면 좋은 사람 안 옴, 불합격자는 통장 사본·신분증으로 비용 처리).
- **한 명씩 늘려라** — 호흡 맞는 한 명을 제대로 키운 뒤 늘리기.
- 수정과 정산 — 미리 합의: CID 걸리면 프리에게 2회까지 수정 → 이후 대표가 직접. 프리 2회 + 대표 2회에도 안 되면 **버리고 돈은 전액 지급**(작품을 잘못 고른 건 대표 실수). 대표가 수정해 25분이 23분이 되면 수정본 기준 지급(사전 합의). 세금: 3.3%가 아니라 고소득 구간은 45%까지(35,000원 주면 실제로 45,000원짜리 지출). **일감이 끊기면 사람이 떠난다** — 3일에 한 편씩 주면 한 달 10편 200만 원이 되어 정직원처럼 붙어 있음.

### 숫자로 주는 지시서 — 실무 과제가 곧 피드백 기준표
- **작가 과제**: 영상 + 자막 + 레퍼런스 스크립트를 주고 "이 형식으로 원본 30분까지, **편집자가 바로 쓸 수 있게 타임코드를 넣어** 써주세요."
- **편집자 과제**: SRT 자막 + 스크립트 + 나레이션 음성(TTS)을 주고 편집. 조건:
  - **컷**: 한 클립 **3초를 넘기지 말 것. 변조한 영상은 6초까지 허용.** 클립과 클립 사이는 **3초 이상 비울 것**(징검다리처럼 = 공정 사용).
  - **오디오**: 사운드바를 켜두고 **재생 중 기준점 -6dB 부근에서 유지**. 게인 값을 -6, -7로 맞추는 게 아니라 **실제 재생 시 미터가 -6에서 놀도록**.
  - **나레이션 구간**: 겹치는 원본 음성은 **-25**로 내려 대사가 나레이션을 묻지 않게. 나레이션 중간 호흡은 짧게, 마는 줄일 것.
  - **자막**: 나레이션과 겹치는 원본 자막은 해제하거나 삭제.
  - **클립 이음새**: 프리미어는 지속 게인으로 부드럽게. 캡컷은 안 해도 됨(오디오 두 개를 겹쳐 페이드 인·아웃).
  - **제출물**: 프리미어는 프로젝트 파일, 캡컷은 드래프트 폴더 원본을 압축. 기한은 서류 합격일로부터 일주일.
  - **스크립트는 뼈대**: "클로드가 쓴 스크립트는 편집을 모르고 쓴 것이니, **내용을 빼도 되고 없는 장면을 추가해도 된다**." 내비가 알려준 길이 막혔으면 다른 길로.
- "이해가 안 되는데 설명해 주실 수 있나요?" 문의가 오면 — 죄송하지만 불합격.

### 작업 관리 보드 — 사람이 놀지 않게
- 흐름: 작품 선정 → 작가 배정 → 준비됨(스크립트 도착) → 검수·휴먼 터치 → 작가 지급 예정 → 녹음 → 편집자 배정 → 검토 중(컷 체크·CID 확인·업로드 후 며칠 관찰) → 편집자 지급 예정 → 작업 종료.
- 돈 관련 칸은 따로 — 요일을 정해 정산(강사는 매주 금요일, 12시 이전 제출분까지).
- 일시정지 칸: 배급사 정책이 갑자기 바뀌면 어느 단계까지 진행됐는지에 따라 세워둠. 기다려도 안 되면 폐기하거나 쇼츠로 전환.
- 핵심은 '사람이 놀지 않게' — 마음에 드는 작가에겐 작품을 미리 여러 개 쌓아두고 "시간 나면 하세요".
- **완성본은 무조건 내 하드에** — 프리에게 프로젝트 파일을 받는 이유는 **나중에 재사용 항소를 할 때**. 프리가 잠수 타면 항소 불가. "아무리 믿어도 인감도장은 안 맡기는 것". (강사는 8TB 외장하드 여러 개 + NAS(공유용) + DAS(보관용))

## 4. 오디오 맞추는 법 — 계산은 산수

- 목표: 시청자가 볼륨 버튼을 딸깍거리지 않게. "대표님은 카메라 감독이자 오디오 감독."
- 방법: 오디오 미터를 켜고 ① **내 TTS 나레이션**이 몇에서 노는지(예: -6) ② **원본 대사 구간**이 몇에서 노는지(예: -12~-20, 중간값 -16) ③ **차이만큼 원본을 일괄로 올림**(+10) → 둘 다 -6에서 놂.
- **먼저 하세요** — 편집 다 하고 클립마다 만지면 지옥. **원본 상태에서 미리 올려두고** 편집 시작.
- **터지는 구간은 내린다**: 일괄로 올리면 총격전·폭발 구간 파형이 주황색으로 깨짐 → 그 파트만 적당히 내림. 원래 그 사운드는 영화 오디오 감독이 의도한 것이니 과하게 손댈 필요 없음.
- 나레이션 겹치는 구간: 원본을 **-25**("대사가 나레이션을 묻지 않게"의 실제 숫자).
- 목소리가 낮게 깔리는 분: 잘 들리기만 하면 나레이션을 더 키워도 됨.
- 일괄 노멀라이즈: 캡컷 오디오 탭의 **음량 노멀라이즈**를 누르면 **-23**으로 한 번에(이후 컷을 자르면 값이 흔들려 확인 필요). 수강생 팁: **설정 → 편집 탭에서 '유튜브용 음향'으로 목표 음량 -14**.

## 5. 3초 컷을 우회하는 법 — 오디오와 영상을 분리한다

- "이 명대사를 5초 통으로 쓰고 싶은데 3초 컷이라면서요?" → **원본 오디오는 그대로 쓰되, 화면은 다른 구간에서 끌어온다.** 영상은 영상대로, 음성은 음성대로 각각 공정 사용.
  - 선택지 1: 오디오도 컷도 그대로 가고 **기억해 뒀다가 걸리면 수정**.
  - 선택지 2: 오디오는 살리고 **화면만 다른 데서 끌어다 붙임**(뒷모습, 듣는 인물의 리액션, 앞서 건너뛴 컷). 회상하다 빡이 친 느낌처럼 오히려 연출이 됨.
  - 선택지 3: 오디오를 살리고 **마를 최대한 타이트하게 줄여** 컷 길이를 맞춤.
  - **슬로우는 비추천** — 3초를 5초로 늘리려면 66%까지 늦춰야 해서 티가 많이 남.
  - 응용: 나레이션(TTS)이 12초면 그 아래에 3초 컷 영상 4개를 깔기. 오디오를 9초 쓰고 화면은 3+3+3으로 달리 가져가도 됨.
- **음악도 똑같다** — "영상은 무섭고 음악은 괜찮다"는 착각. **기준은 똑같이 6초**, 가사 유무가 아니라 그 음원 저작권자가 얼마나 민감한지. 12초를 써도 되는 음원이 있고 8초에 날아가는 영상이 있음.
- **오디오 위주로 편집하면 자동으로 지켜진다** — 마를 없애며 붙이다 보면 컷을 길게 쓰는 것 자체가 어려움. 직원이 화리라고 12초씩 쓰면 강사가 되레 수정시킴(퀄리티가 안 나와서).

## 6. 소재 발굴 — 작품이 아니라 배급사를 고른다

> **"작품을 고르는 게 아니라 배급사를 골라서, 그 배급사를 등골까지 빨아먹는 게 핵심입니다."**

- **What's on Netflix**: 비공식 팬사이트 겸 뉴스. 이번 달·올해 추가 타이틀, 공개 예정작, 평점, 날짜별 신작. 구글 번역으로 충분. 2026년은 3분의 2 지점에 이미 1,600개 추가.
- **어그로 소재**: "2016년 8월 1일 넷플릭스에서 공개된 문제작", "전 세계 8,270만 시간 시청한", "공개되자마자 89개국 1위" — 거짓말이 아니라 실제 수치라 태클 들어와도 문제없음. 한 번 컨셉 잡으면 시리즈로.
- **키노라이트 · Flixpatrol**: 순위·시청시간 추적(Flixpatrol은 유료화 월 7.5만 원이라 요즘 잘 안 씀).
- **나무위키**: 넷플 오리지널 목록에서 배급사·제작사 확인. **넷플은 자체 스튜디오가 없어 제작사가 따로** — 이탈리아 작품처럼 제작사가 직접 때리는 경우 주의.
- **MGM = 아마존 자회사**: 아마존 오리지널 상당수를 MGM이 담당. 다만 **제작은 MGM인데 해외 배급이 소니픽쳐스로 넘어간 작품은 걸림.** 공개된 지 얼마 안 된 최신 오리지널일수록 단속이 강하고, 오래된 오리지널은 약함.
- **다큐멘터리를 노려라**: 한국 콘텐츠는 쳐다도 보지 말라 했지만 **다큐는 예외적으로 낫다**(「나는 신이다」「나는 생존자다」 같은 실화 다큐는 영화·드라마 리뷰와 결이 맞음, 다큐만 17편으로 돌리는 대형 채널도). 인물이 말하는 장면 위에 나레이션을 덮는 방식.
- **크리에이티브 커먼즈**: 원작자 출처만 밝히면 영리 목적으로도 복제·수정·2차 저작 가능. 유튜브 업로드 시 미리 설정 가능.
- **유튜브 영화 구매**: 1,100~1,500원에 소스 확보하는 채널도. 전쟁·구작처럼 웹하드에 없는 작품은 이 방법이 깔끔.
- **소싱 자체를 벤치마킹**: "넷플릭스만 파는 채널", "아마존만 파는 채널"이 실재 → 구독해 두고 어느 배급사를 털지 정함. 모르겠으면 **OTT로** — 대기업이라 경고·차단 이상의 리스크는 거의 없음.
- **컷 길이에 갇히지 마라**: 넷플은 컷이 짧을수록 좋음. 대사 한 마디가 보통 3~4초라 "한 컷 쓰고 다음은 안 쓴다"가 공정 사용 감각이지, **12초를 써보고 걸리면 수정하는 것도 방법**.

## 7. 누가 때리고 누가 넘어가나 — 전부 이익과 손해의 계산

- **법무법인**: 합의금 장사도 진행 비용보다 이익이 커야 움직임 → 지급 능력이 없는 사람은 아예 안 때림.
- **국내 중소 배급사**: 결말이 포함되든 말든 작품이 노출돼야 한 건이라도 팔리고 원가 회수 → 묵시적으로 허락.
- **B급·구작**: 아무도 안 봐주는 작품일수록 리뷰 자체가 마케팅. 유튜브 영화나 OTT 결제로 이어지길 바라니 넘어감.
- **넷플릭스가 숏폼을 봐주는 이유**: 캐팅(홍보)이기 때문에 지금은 참는 것.
- **파라마운트가 관대한 이유**: 관리에도 인건비·외주비가 듦. 비용 대비 실익이 적으면 안 함.
- **그럼 언제 때리나**: **실익을 뺏길 때.** VPN으로 국내 미공개작을 선점해 올리거나 다음 주 국내 개봉 예정작을 미리 올리는 것 — 선을 넘는 것.
- **결론: 원본을 대체하지 말고 홍보처럼 하세요.** 적당히 홍보해 주되 실익은 뺏지 않는 선이면 웬만하면 넘어감.
- 민통선 비유: 국내 드라마 리뷰가 여전히 있는 건 리스크를 알고 이익이 더 크다고 판단해서. "쟤는 한국 드라마 하는데?" 하고 따라 하다가 맞으면 아픔. 초병이 경고하는 선이 있고, "나는 감당할 수 있다"면 넘어가도 됨 — 대표 책임.

## 8. 지표 읽기 — 네 개 탭만 본다

- 유튜브 스튜디오 분석에서 **개요는 뻔하고, 도달범위·참여도·시청자층**만. 수익은 나중에 웃으면서. 채널이 아니라 **영상 하나를 클릭해 들어가서** 봐야 디테일.

### ① 도달범위 — 노출 클릭률(CTR)은 썸네일·제목의 성적표
- **6~10%가 평범, 10% 이상이면 터짐, 5% 미만이면 썸네일과 제목을 바꿈.** 단 유효 노출이 1,000회 이상 쌓인 뒤에 판단. 2%대는 심각.
- **2~3주는 기다린다** — 2주 동안 바닥을 기다가 알고리즘을 타고 우상향하는 영상이 흔함. 초반에 분석할 시간에 영상을 하나 더 올리는 게 나음.
- 노출이 많은데 CTR이 낮으면: 유튜브가 관심 없는 사람에게까지 "잡숴봐"를 반복하는 중. 방치하면 2.5%까지 떨어짐.
- 트래픽 소스: 추천·탐색 기능·검색·최종 화면·외부. **검색 유입이 많으면 그 키워드를 제목·설명에**, **추천 유입이 많으면 알고리즘이 밀어주는 중이니 비슷한 작품을 이어서.** 결론은 같음 — **장르를 맞춰 밀어붙이는 것.**
- 검색 키워드: 썸네일·제목에 작품명을 안 썼는데도 "몰아보기·결말 포함·배우 시리즈·웃긴 장면 모음" 같은 키워드로 노출 → 그 키워드에 다음 작품을 맞추면 유입 증가.

### ② 참여도 — 시청 지속률은 영상 내용의 성적표
- 롱폼 **20~25%가 정상, 15% 미만이면 반성**(강사 채널 평균 24%).
- 조회당 시청 시간 **5~6분 이상**이 가장 깔끔.
- CTR은 높은데 지속률이 낮으면: 썸네일은 기가 막힌데 내용이 딴판 — 썰어대는 썸네일에 낚였는데 요리 영화였던 격.
- 하락 구간: 작품 설명(엔딩) 파트에서 뚝 떨어지는 건 정상("결말까지 봤어, 먹을 거 다 먹었어").
- 좋아요:싫어요 — 아무리 잘해도 9:1 정도. 싫어요는 항상 있음.
- **수익화까지 산수**: 20분 × 지속률 25% = 조회 1회당 5분. 4,000시간 = 240,000분 ÷ 5 = **48,000회** → **20분짜리로 총 5만 조회면 시청 시간 조건 끝.** 1시간짜리면 1만 조회로도. 남은 건 구독자 — 쇼츠로 수급.

### ③ 시청자층 — 컨셉과 톤과 업로드 시간을 알려준다
- 연령·성별: 드라마 몰아보기, 배우 컨셉 모음집 모두 **남성이 더 많고 35~54세가 약 60%.** 10~20대는 애니 비율이 극단적으로 높으니 과감히 버리고 30대 이상 겨냥.
- 그래서 톤도 정해짐: 나레이션이 너무 잔잔한 것 같아도 괜찮음. 40~50대에게 과한 밈·드립은 오히려 이탈 요인. **연령대가 곧 컨셉.**
- **한국 비율 90% 이상이 정상.** 해외가 20%씩 잡히면 알고리즘이 아직 채널을 파악 못 한 것 → 한국어 영상을 몇 개 더 올려 방향 잡기.
- 업로드 시간: '내 시청자가 유튜브를 이용하는 시간대' 표. 대개 **저녁 8시 피크.** 알고리즘 예열을 원하면 1~2시간 앞당겨(오후 4~6시), 공개 즉시 터뜨리려면 8시.
- **새벽 업로드는 자살행위** — 주말에 밤새 완성했으면 **키핑했다가 저녁에.**
- 주기: 동일 요일·동일 시간 공개 추천(시청자 습관). **3일에 한 편이면 충분.**

### ④ 채널 페이지·재생목록 — 힘 안 들이고 얻는 유입
- 대형 채널은 하나같이 **비구독자용 영상 / 회원 전용 영상(상단) / 추천 동영상 / 재생목록 여러 개 / 추천 채널**을 전부 세팅(돈을 쓴 멤버십 회원이 먼저).
- 어떤 채널의 '지리는 시리즈' 재생목록은 영상 90개에 **재생목록 경유 조회만 282만.** 조회가 안 나오던 영상도 시리즈로 묶으면 끝까지 재생됨.
- 강사 채널 총 노출 7,200만 중 탐색 기능 7.3% / 채널 페이지 5% / 재생목록 3% → 채널 페이지 + 재생목록 합치면 알고리즘이 밀어주는 탐색 기능과 맞먹음.
- 언제 세팅: 영상 하나뿐이면 겹쳐서 안 예쁨. **영상이 20~30개 쌓인 순간** 홈 탭에 섹션 추가.

| 증상 | 무엇을 고치나 |
|---|---|
| 클릭률이 낮다 | **썸네일·제목 수정.** 지금 당장, 2년 전 영상도 바꿀 수 있음 |
| 클릭률은 높은데 지속률이 낮다 | 썸네일이 낚시이거나 초반 편집 문제. 잘 만든 썸네일이니 **초반 편집을 손봄** |
| 둘 다 괜찮은데 노출이 안 된다 | 알고리즘 **미세조정 중.** 기다림 |
| 둘 다 나쁘고 노출도 안 된다 | 작품·소재 문제. 레이어를 조정하되 일단 기다림 |
| 특정 지점에서 이탈이 급증 | 그 구간이 루즈한 것. 다만 **이 영상이 아니라 다음 작품에서 고친다** (썸네일은 언제든 바꿀 수 있지만 편집은 못 바꾸니까) |

- 완벽주의가 제일 손해 — 조회수만 쳐다보다 멘탈이 바사삭. **그 사이에 하나 더 치는 게 낫다.**
- 알고리즘 반응은 지연됨 — 시청 시간 집계도 일주일쯤. "왜 숫자가 안 맞죠?"는 대부분 아직 반영 안 된 것.
- 방향은 달리면서 바꾼다 — 동쪽으로 가면 동해, 서쪽으로 가면 서해라도 봄. 내비만 쳐다본다고 방향이 바뀌지 않음.

## 9. 수강생 채널 실시간 진단에서 나온 실전 규칙

- **썸네일은 3개 이상 미리 만들어라** — 강사는 컷을 여러 개 골라 4~5개 만들어 둠. A컷이 안 되면 B컷, 안 되면 C컷, 그래도 안 되면 다음 작품.
- **A/B 테스트는 양날의 검** — 3단계 인증 필요, 유튜브가 후보를 전부 돌려봐서 결과가 오래 걸림. "길게 보겠다"일 때만.
- **업로드 텀은 짧게 자주보다 3일 + 길게** — 이틀 간격으로 짧은 걸 올리기보다 3~4일 텀으로 늘리고 분량을 합치는 쪽이 나음. 단편은 여러 편 묶어 20~25분으로.
- **분량은 최소 8분 이상**(반복된 지적) — 8분을 넘겨야 광고가 하나 더 붙고 시청 시간도 빨리 참.
- **CID가 떠도 대한민국 공개가 되면 올린다** — 영상이 많지 않을 땐 붙잡고 있는 것보다 올리는 게 맞음. 이의제기는 신고자 회신까지 최대 30일이라 그동안 묵혀두는 도박수도(삐진 권리자가 경고를 줄 수도).
- **엔딩 화면 클릭률 0%는 잘못이 아니라 영상 개수 부족** — 올릴수록 내 영상에서 내 영상으로 유입이 돌기 시작.
- **설명란·태그는 기본값으로 저장** — 인사말·출처·좋댓구알을 미리 세팅해 두고 링크만 바꿔 끼움. 태그는 "아마존 프라임 / 영화리뷰 / 결말포함" 정도면 충분.
- **댓글 설정**: URL·해시태그가 포함된 댓글은 **'검토를 위해 보류'**(불법 링크 스팸).
- **제목의 괄호**: 유튜브가 인식하는 문자라 **( )**를 씀. 꺾쇠도 되지만 괄호가 더 예쁨.
- **피벗(장르 전환)**: 강사는 **일괄 삭제** 추천. 불안하면 새 영상 하나 올리고 옛 영상 하나 내리는 식으로 냄새를 빨리 벗기기. 구독자가 이미 있는 채널이면 버리지 말고 갈아끼우기.
- **니치 마켓(SCP·공포)**: 노출이 많아도 클릭률이 낮다가 알고리즘이 타겟을 잡는 순간 올라감. **꾸준히 올려 그 사람들을 붙잡는 게 전부.**
- 구독자 구매 실제 조언: 시청 시간은 잘 나오는데 구독자만 없는 채널에 "3,000시간 찍으면 500명 정도 사겠다". 너무 일찍 말고, 한 번에 말고 2주~한 달에 걸쳐 천천히. **맞구독은 하지 마세요**(100명 중 100명이 겹치면 어뷰징 신호).

## 10. 경쟁자 역추적 — 트래픽 소스에서 시작한다

- "다른 동영상에서 유입된 목록"을 열면 **내게 조회수를 보내준 남의 영상들** — 경쟁자가 아니라 동료.
- 추적 순서: 유입 영상 확인 → 그 채널 눈팅 → 업로드 주기·평균 길이·평균 조회수 → 수익 추정 → **그 사람이 쓴 작품과 소스 출처까지.**
- 실제 사례: 전쟁 영화만 다루는 15만 구독 채널 — 주 1회, 12~13분, 평균 10~15만 회 → 주당 30만, 월 180~200만 원. 소스는 유튜브에서 1,100~1,500원에 산 구작, 크리에이티브 커먼즈 표기까지 → "달달한 부업이네" 하고 파악 끝.
- **남이 잘 돼야 내가 잘 된다** — 검색량이 낮은 작품은 **추천 동영상**에서 우위. 같은 작품을 다룬 남의 영상이 터지면 내 영상으로도 넘어옴. **경쟁자가 아니라 동승자.**
- **사라진 채널을 확인하라** — 시청자가 함께 보는 채널 목록에서 이름 검색 → 없어졌다면 저작권 3아웃. 실제로 **구독자 66만·조회수 3억 채널이 저작권 신고 누적으로 통째 삭제**(영상 410개, 아무것도 안 하고 살려만 뒀어도 됐을 채널).
- 권리자 추적: 삭제된 영상의 신고 주체가 법무법인이면 진짜 업무 위탁이거나 저격. 반대로 **살아남은 작품들은 상대적으로 안전하다는 신호.**
- **벤치의 진짜 리스크**: 내가 그 사람 눈에 띄었는지 알 수 없음(그 사람 영상의 재사용이기도 함) → **벤치로 수익화를 뚫었으면 빨리 공정 사용이나 화리로 넘어가라.**
- **트렌드 탭**: 분석 → 콘텐츠 말고 바로 트렌드(아이디어) → 유튜브가 **"다음 동영상을 위한 아이디어"**를 직접 줌. 엉뚱한 주제만 뜨면 알고리즘이 아직 채널을 파악 못 한 신호.
- 사라지지 않는 것이 우선: tvN 등 국내 방송사 콘텐츠는 워터마크를 지우든 말든 날아감. 대형 채널도 예외 아님.

## 11. 수익 다각화 — 만든 걸 뿌리는 정도로

- **4대 플랫폼**: 유튜브 쇼츠 · 인스타 릴스 · 틱톡 · **네이버 클립.** 하나 만든 걸 네 곳에.
- **워터마크 금지**: 각 플랫폼이 자사 워터마크 박힌 영상 노출을 제한한다는 얘기(공식 부인, 체감은 다름). 캡컷에서 틱톡으로 바로는 괜찮지만 **틱톡에서 받아 다른 데 올리면 워터마크.** 항상 원본으로.
- **네이버 클립**: 팔로워 1,000명 초과 + 90일 유효 조회 300만. 매월 15일 개별 안내, 상시 지원. 크리에이터 선정이 먼저, 정산(기준액의 45%) — **사실상 허가제.** 안 되면 다음 달 다시.
- **인스타·틱톡**: 조건이 까다로움(팔로워 1만, 30일 10만 조회 등). 다만 **수익보다 유튜브로의 유입**이 목적(실제로 롱폼 유입이 꽤). 틱톡은 **1분 이상**이어야 하니 앞뒤 컷을 늘림.
- **멤버십(회원 전용)**: 차별화 필요 없이 **선공개**면 충분. 조회수 800만인데 노딱 걸려 내리기 아까운 영상, 이달 수익 조절용으로 회원 전용 전환(네이버 웹툰 미리보기 같은 감각).
- **롱폼 → 숏폼 재활용은 30% 바꿔라**: 같은 유튜브 안에서 너무 똑같이 쓰면 재사용으로 채널 정지(90일 개점 휴업). 잘라둔 구간을 앞뒤로 3초·1~2초씩 늘리거나, 나레이션과 장면 순서를 바꾸거나, 스크립트 문체를 바꾸고 자막 타이밍을 옮기기.
- **쿠팡 파트너스 등**: 영화·드라마는 쇼핑 링크가 잘 안 맞음(월 100~200만 원 수준). 차라리 **수익창출을 뚫어놓고 채널을 판매**(40만~80만 원대, 해외 인도·베트남 매물은 허위 조회수로 쉽게 날아감).
- **숏폼 vs 롱폼**: 숏폼은 휘발유 — 주 1,000만 조회가 나와도 월 800~900만 원이 맥시멈이고 매일 넣어줘야 탐. 롱폼은 석탄 — 생산은 오래 걸리지만 자동화·고용으로 손을 놔도 굴러감. **둘 다 가져가되 주력은 롱폼.**
- **내 영상을 남이 퍼 갔다면**: TTS로 만든 영상은 '내 것' 증명이 어려움. 지무비처럼 **목소리·시그니처가 뚜렷하면** 경고를 걸 수 있음. 반대로 우리는 그 자리를 이용해 유입을 가져가는 쪽.

## 12. 레이어를 섞어라

- **하이 리스크**: 국내 신작 드라마 — 지금 달달한 건 알지만 수명이 짧음. **소량만.** 영드 롱폼은 재사용에 걸리는 끝판왕(강사 채널도 안 걸린 게 손에 꼽음, 전부 항소로 통과).
- **미들 리스크**: 외국 신작, 유명 구작 — 어느 정도 예측 가능.
- **로우 리스크**: 비주류 구작, OTT 구작, 화이트리스트, SCP — 소재 고갈 없어 **루틴용으로 물량**.
- 셋을 섞으면 신고를 한두 개 맞아도 위험한 쪽을 비공개로 돌리고 안전한 트랙으로 업로드 텀 유지. 혼자 1~2채널, 프리 한 명 끼면 2~3채널.
- **본업은 유지하세요** — 체력·건강이 받쳐주는 선에서 본업을 깔고 유튜브를 얹기. 유튜브가 날아가도 월급은 들어옴.
- **순서를 지키세요**: 벤치로 수익화 → 그 돈으로 공정 사용 도전 → 힘듦과 통과의 희열을 맛본 뒤 → 화이트리스트. 화리는 돈이 투자되는 작업이라 앞 단계를 겪어봐야 가치를 앎.
- 항소는 영상이 아니라 채널 단위 — 항소한 뒤 영상을 삭제하면 안 되고, 통과됐다고 생짜깁기로 돌아가면 바로 날아감(독감 백신 맞았다고 겨울에 웃통 벗고 다니면 안 되는 것).

## 13. Q&A

- **4K로 편집할 필요?** 없음. 유튜브 프리셋 1080 + AAC 128로 인코딩되니 4K 원본 고집은 의미 없음.
- **효과음**: 강사는 안 씀(예술 아님). 편집자에게 "**초반 1분에 2~3개만**". 넣은 분들 잘했지만 없어도 됨.
- **대사 자막을 나레이션 구간에 넣는 이유**: 재사용 대비가 아니라 그냥 퀄리티 — 시선을 자막에 묶어두려는 최소한의 장치.
- **SRT를 캡션으로 가져왔을 때**: 잘라도 캡션만 따로 잘림 → Ctrl+A → 연결 해제 → 다시 Ctrl+A → 연결해야 같이 잘림.
- **자막을 못 구했을 때**: 유자막 화면을 확대해 아래를 잘라내는 것만으로도 됨("옛날 영화는 화질이 안 좋나?" 하고 봄).
- **편집이 너무 오래 걸림**: 큰 씬마다 자른 뒤 그때그때 나레이션을 만드는 구조라서. ① **풀 대본을 먼저 완성** → ② 사전 세팅 + 2차 편집(미러링·색조 등)을 미리 → ③ 전체 컷 편집 → ④ 후작업(자막·템플릿) → ⑤ 업로드.
- **CID가 쉬운 작품은 어떻게 아나**: 결국 경험. "이 배급사는 내 편집법과 맞는다"가 쌓이면 기준. 같은 UPI 작품인데 누구는 통과, 누구는 실패.
- **다큐·액션·스릴러를 한 채널에서?** 됨. 다큐라도 충격 실화 계열이면 스릴러·액션과 결이 맞음. 화리도 그 결에 맞춰 고르기.
- **로코·드라마 단편?** 시청자 남성 비율이 높아 롱폼으론 잘 안 팔림 → 그래서 **미드폼(3분대)**으로 파는 채널이 있음. 도전은 선택, 강사 추천은 아님.
- **화리를 두 채널에?** 안 됨. 본 채널에만.
- **정품 라이선스**: PC 2대까지라 강의용·본컴 오가면 매번 로그아웃·로그인.
- **캡컷과 병행**: 단축키를 서로 맞춰 두기(강사는 캡컷 단축키를 프프에 맞춤).

### SCP — '무료 화이트리스트'에 가까운 니치 마켓
- 정체: 2008년경부터 인터넷 게시판에서 집단으로 만든 **가상 괴생명체·괴담 창작 세계관.** 요즘의 '이탈리안 브레인로트'(퉁퉁퉁 사후르 등)와 원리가 같음. 한국 지부(SCP-###-KO)도 있음.
- 왜 좋나: **CC BY-SA**라서 원작자 출처만 밝히면 2차 창작·영리 이용이 자유. 편집도 거의 필요 없고 나레이션으로 채우는 구조라 부담이 적음. **돈 안 쓰고 안전한 국밥 트랙**을 하나 갖고 싶을 때 정답.
- 단점: 트래픽이 적음. 노출이 많아도 클릭률이 낮다가 알고리즘이 타겟을 잡으면 올라옴. **분량을 늘리고 꾸준히 올리는 게** 유일한 해법.
- 선택 기준: 빠르게 돈부터 → **액션·SF**, 안전하게 오래 가는 걸 하나 → **SCP**.

## 14. 55일 챌린지 (종강과 함께 시작 — 이게 진짜 본편)

- 목표: 55일(약 8주) 동안 **롱폼 16개**(일주일에 2개, 3일에 1편). 숏폼은 선택, 챌린지가 끊길 위기에 쓰는 **목숨 3개**로만 인정(롱폼 16 + 숏폼 3 = 19회).
- 작성법: 사담방/게시판에 `무비마스터 2기 챌린지 - N일차 + 나만의 소제목`. 업로드 날짜와 글 쓴 날짜를 맞춰야 함.
- **3일 규칙**: 최소 3일에 한 번 글. 1일차에 썼으면 4일차까지는 되지만 8일차는 실패. 텀이 끊기면 1일차부터 다시.
- 시작: 강의 시청 후 일주일 이내(종강 다음 날 8/7부터 시작해도 됨).
- 무엇을 올리든 상관없음(벤치·공정 사용·무료 화리·유료 화리·프리미엄 화리·SCP — 돈 벌 장르로).
- 완주 보상: 성과와 무관하게 치킨. 성과 보상: 구독자 1,000/5,000/10,000/30,000 각 치킨, 50,000명 한우, 조회수 1만 인증도 치킨. 완주 + 인증 → 순금(1년 이내).
- 과제 제출률(공개 숫자): 1주차 44%, 2주차 32%, 3주차 22%. **"아무리 열심히 알려드려도 하지 않으면 의미가 없습니다."** 55일 동안 롱폼 16개를 하고도 수익창출이 안 됐다면 따로 미팅.

## 16. 딱 기억할 3줄

1. 편집이 가장 오래 걸리는 공정이니 **편집부터 넘긴다.** 대표는 작품 선정과 최종 판단, 지표 관리만 — 손을 떼는 게 아니라 최종 감독자로 승진.
2. 사람에게 주는 지시는 전부 숫자다. **컷 3초(변조 6초), 간격 3초 이상, 나레이션 -6dB, 겹치는 원본 -25.** 이 숫자가 그대로 피드백 기준표.
3. 지표는 딱 둘만 본다. **CTR 5% 미만이면 썸네일을 지금 바꾸고, 이탈 구간은 이 영상이 아니라 다음 작품에서 고친다.** 20분 영상 5만 조회면 수익화 시청 시간은 채워진다.

## 17. 1~3강과 맞춰 본 것 (4강에서 확정·수정된 숫자)

- **컷**: 원본 한 클립 3초 이하 / **변조(미러링 등)한 영상은 6초까지** / 클립 사이 3초 이상 비우기 → 2강 "3-3"과 같고, 변조 시 6초 허용이 새로 추가.
- **오디오**: 재생 미터 기준 나레이션·원본 모두 **-6dB 부근**, 나레 겹치는 원본 **-25** (3강의 -15~-25 / -35~-50보다 구체). 캡컷 노멀라이즈 -23, 유튜브용 음향 -14.
- **음악도 6초.**
- **썸네일**: 가로 3~4등분 폭을 채우는 큰 글자, 한 줄, 앵커 인물 얼빡, 글자 살짝 아래, 흰 글자 + 검은 외곽선, 노랑·빨강, 물음표형 문구, 해상도 업.
- **쇼츠**: 마 없애기, 대사는 살리거나 죽이거나, 30초보다 길게(나레 비율↑), **제목을 화면에**, 나레 자막 ≠ 원본 자막, 한 컷으로 갈 수 있으면 한 컷.
- **업로드**: 3~4일 텀, 동일 요일·시간, 저녁 8시(예열이면 4~6시), 새벽 금지, 최소 8분.
- **벤치 → 공정사용 → 화리 순서**, 벤치로 수익화 뚫으면 빨리 넘어가기(1·3강과 일치).
- 넷플: 한국 작품 X, 구작 외화 O, 화리 없음(2강과 일치). 아마존 오리지널 = MGM(소니 배급 작품 주의).

## 18. 우리 작업에 옮길 수 있는 것 — 후보 (적용은 사용자 확인 뒤)

1. 오디오 자동화: 나레(TTS)와 원본 대사의 재생 레벨을 측정해 원본을 차이만큼 일괄 보정 → 둘 다 -6dB 부근, 나레 겹치는 구간 원본 -25dB, 폭발 구간만 따로 낮춤. (ffmpeg loudnorm/volume으로 가능)
