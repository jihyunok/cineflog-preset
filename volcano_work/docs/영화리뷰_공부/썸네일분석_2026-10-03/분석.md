# 영화리뷰 벤치 썸네일 분석 (2026-10-03)
> 롱폼은 섬네일이 굉징히 중요한거알지 패밀리플렌 섬네일 다시한번 확인해봐 엄마까지 당했다하고 화면위에 형광연녹색으로 후킹되는말 한마디 넣어주고 섬네일 이미지도 좀더 후킹갈만한 영상 좀더 찾아봐 와 00이라고? 뭐 이런 느낌
> 섬네일 들을 다 분석해봐

채널 8곳의 최근 200편 가운데 조회수 위 12편씩, 모두 96장 (sheet_*.jpg).
지무비(340~570만) · 드림텔러(200~470만) · 무비트립(130~350만) · 멀더의 무비파일(130~510만) · 영반(74~570만) · U무비(93~220만) · 제이슨무비 · 서울극장.

## 거의 모든 썸네일이 같은 것
1. **아래 한 줄 큰 글씨 = 흰 앞말 + 빨간 뒷말**, 두꺼운 검은 테두리 (96장 중 약 80장). 우리 thumb_ref 꼴이 맞다.
2. 말투는 **대사체/선언**: "모조리 죽여주마" "지금부터 전부 죽는다" "감히 내 딸을 건드려?" "니들 이제 X된거야" "너희들.. 실수한거야".
   또는 **평가체**: "진짜 X나 재밌음" "2025 최신작" "아마존 1위" "넷플릭스에 없음" (멀더·U무비·제이슨무비).
3. 사진 = 인물 한 명 크게, **피·상처·담배·문신·총·시체 더미** 같은 센 것. 웃는 얼굴은 코미디 채널만.

## ★위쪽 작은 한마디 (사용자가 말한 형광 연녹색)
- 무비트립 "(특수부대 최정예 요원)->" "(여자 존윅)" "(조선판 장이수)", 드림텔러 "(강남 갑질러) (자산 1조 CEO)", 서울극장 "(전설의 킬러)" "(로버트 패틴슨)", 영반 "비리 경찰" "존나 재밌음", 제이슨 "(촉법10대)" "실화".
- ★길이: **2~8자**. 사용자 "연두색글자가 너무 길어 너 분석한거맞아?" (12자+ 넣었다가 퇴짜).
- 꼴: **형광 연녹색(약 RGB 110,255,40) 굵은 고딕 + 검은 테두리**, 아래 큰 글씨의 40~50% 크기, 위쪽 가운데나 인물 머리 위. 괄호로 인물 정체를 붙이거나 짧은 후킹("싸움의 '신'", "LV.999 인간병기").
- 역할: 아래 큰 말이 "무슨 일"이면 위 연녹색은 "누가/왜" → 둘이 합쳐 궁금증.

## 우리 채널에 옮긴 것
- `presets/시네플로그/thumb_hook.py` = thumb_ref 꼴 + 위 연녹색 한마디 ("와.. ○○라고?").
- 02 패밀리 플랜: 썸네일2 = 피 흘리며 쓰러진 엄마(6269.1s) "와.. 킬러라고?" + "엄마까지 / 당했다", 썸네일3 = 피 묻은 엄마 얼굴(6339.0s) "(킬러의 아내)". 옛 썸네일2 는 _옛썸네일/.

## 사용자 평
> 차리첫번째가 제일 나아
> 아니 제~~~일 처음에 만든거 / 엄마도 몰랐다고? 이정로 / 어 맞아 이거
- ✅ 확정: 맨 처음 썸네일2(머리채 잡힌 엄마, 뺨 상처 + "엄마까지 / 당했다") 그대로 + 위 연녹색 "엄마도 몰랐다고?"(62px) → 사용자 "가족을 건드려? 이걸로 바꿔줘" → "가족을 건드려?". 오늘 새로 고른 장면 둘은 _옛썸네일/.
- 배운 것: 장면은 옛것이 더 나았다 — 새 장면을 찾기보다 위 연녹색 한마디만 짧게 얹는 게 맞았다. 문구 꼴은 "○○도 몰랐다고?".

## 03 아이 돈 언더스탠드 유 (사용자 "3번영화")
- 장면·아래 글씨 그대로 + 위 연녹색만: 썸네일1 "이게 여행이라고?" · 썸네일2 "저녁 먹다가?". 원본은 _옛썸네일/*_초록줄전.jpg. 평 대기.

## ★최종 (사용자 캡처 「싸움의 신」·「조폭 VS 조선족」 "이런스타일")
- 위 한마디 = 흰 앞말 + 빨간 뒷말, 크기 아래 글씨의 약 55%. 연녹색·작은 글씨는 버림. 02·03 썸네일 모두 이 꼴로 다시.

## ★위 한마디 = 줄거리 말고 벤치 후킹 문구 (사용자)
> 아니 글자말이야 니들은 X됐어  개봉하자마자 1위찍은 영화이런말로 바꾸라고 이런섬네일 제목들 찾아서 하라고 / 내용을 넣는게 아니라
- 위 한마디에 줄거리("가족을 건드려?" "이게 여행이라고?")를 넣지 않는다. 벤치 썸네일에 실제로 쓰인 문구 꼴을 쓴다.
- 벤치 문구 모음 (96장에서 받아 적음, 흰/빨강 나눔은 / ):
  - 위협 대사: 니들 이제 / X된거야 · 니들은 이제 / X됐어 · 모조리 / 죽여주마 · 지금부터 / 전부 죽는다 · 감히 / 내 딸을 건드려? · 너희들.. / 실수한거야 · 고맙다? / 먼저 건드려줘서 · 어디부터 / 잘라줄까? · 모조리 / 죽여줄게
  - 평가·순위: 아마존 / 1위 · 2025 / 최신작 · 넷플릭스에 / 없음 · 한국 느와르 영화 / "1위" · 공개하자마자 / 1위 · 미친 / 스릴러 · 역대급 / 몰입감 · 숨겨진 / 명작 · 몰입감 / 개미쳤다 · 진짜 / X나 잘싸움 · 시간순삭 / 생존스릴러 · 간만에.. 도파민 / 터졌습니다
  - 인물 꼬리표(위 작게): 싸움의 / "신" · LV.999 / 인간병기 · 전과 / 26범 · (전설의 킬러) · (여자 존윅) · 교도소의 / 신

## ★문구는 내가 찾는다 (사용자 "내가 준말대로 하지말고 니가 좀 찾아봐 섬네일 제목 글자들을")
- 사용자가 예로 든 말을 그대로 쓰지 말고, ① 같은 영화를 다룬 다른 리뷰 썸네일 ② 같은 장르 인기 썸네일을 찾아 문구를 고른다.
- 찾는 법: yt-dlp ytsearch40 "<장르> 영화 결말포함" 등 6개 검색어 → 8분 넘는 영상 조회수 위 12장씩 시트(sheet_킬러아빠·전직요원가족·액션코미디·블랙코미디·여행공포·커플스릴러·패밀리플랜.jpg).
- 같은 영화(패밀리 플랜) 남의 썸네일: "전세계 1위 킬러"(4장, 546만·128만·34만·5만) · "레전드 킬러 1위" · "그 아조씨 건들면.. 다 뒤져요!"(289만) · "너넨 다 뒤졌다!!" · "(ㅈ됐네)" · "진짜 액션 미쳤음".
