2026-09-30 사용자가 4편 썸네일을 보고:
- "고릴라통신 섬네일보고 수정해줘 고릴라통신은 웃고울고감동적인 사람들의 감정을보이잖아"
- "사람들이 무슨일이지?하고 궁금증을 자아내게 만들어줘야지 롱폼은 섬네일이 90프로인데"

**Why:** 내가 만든 썸네일(4칸)은 그냥 말하는 무표정 프레임을 골라서 감정이 안 보였다. 벤치(고릴라통신)는 칸마다 우는·놀란·웃는 얼굴, 입 가리는 손, 눈물이 크게 잡혀 있다. 또 벤치는 편마다 꼴이 다르다(4칸형 대부분, 4위·13위·16위는 얼굴 하나 크게+세로 말풍선+아래 검은 띠 두 줄).

**How to apply:**
- 썸네일 프레임은 원본을 24장 이상 시트로 훑어서 **감정이 가장 센 순간**(눈물·놀람·폭소·손으로 입 가림)만 고른다. 말하는 중 무표정 금지.
- 영상마다 **그 벤치 편의 썸네일 실물**(i.ytimg.com/vi/<id>/maxresdefault.jpg)을 먼저 받아서 꼴을 그대로 따른다.
- 글자는 결과를 다 말하지 말고 "무슨 일이지?" 하게 끊는다(…, 말풍선 한마디).
- 원본 영어 자막이 얼굴·글자와 겹치면 피해서 자른다.

도구(scratchpad/ep): mk_sheet.py N → sheet_eN.jpg(원본당 12칸) · redo.py N "r,c ..." → thumb_emo.py(YuNet yunet.onnx 로 얼굴 찾아 크게) 4칸 교체 · thumb_face.py = 얼굴 하나 꼴(벤치 4·13·18위). 09-30 에 4~24편 전부 이 방식으로 다시 만듦.

- 09-30 추가 지적: "사람들의표정이 잘보이게 위에 글을 빼던지 아래글을 한줄만 하던지 글자 때문에사람들의 얼굴이제대로 안보여" / "너구리빼" → 한 줄은 "너무 밋밋해"로 퇴짜. 최종: "아래 두가자" = 위 띠 없음, 사진 맨 위부터(0~528), 아래 띠에 두 줄(「〜したら」/「→〜」). 띠 색: 노랑은 "노란띠는 아닌거같은데"로 퇴짜 → 최종 "고릴라처럼해 검은띠에 빨간글씨" = **검은 띠 + 두 줄 모두 빨간 글씨(흰 테두리)**. 글자는 "화면에 90프로 차게 가로로" → 두 줄 다 가로폭 90%로 늘림(높이 84). 썸네일에 ポン吉(너구리) 넣지 않는다(로고 속 얼굴도).
