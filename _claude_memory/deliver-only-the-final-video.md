숏폼을 다 만들면 **완성본 영상 하나만** 건네라. `plan.py` · `build.py` · `captions.ass` ·
나레 wav · 받아둔 원본 같은 **중간 파일을 표로 늘어놓지 마라.** (2026-09-05 사용자 지시:
"니가 만든 파일들을 다 안줘도 돼")

**Why:** 사용자는 결과물을 올리려는 것이지 작업 폴더를 들여다보려는 게 아니다.
파일 목록은 다음 세션의 나에게나 쓸모가 있고, 그건 이미 `docs/` 에 적혀 있다.

**How to apply:** **터미널에 완성본 경로를 찍는다.** 재료가 필요할 때는
사용자가 따로 말한다(캡컷 인계처럼). 작업 기록은 저장소에만 남긴다.

★**파일 카드(SendUserFile)로 보내지 마라** (2026-09-10 사용자: "여기 나오는게 아니라
터미널에 나오게 하고싶은데"). 사용자는 같은 PC 에서 폴더를 직접 열어 올린다 —
카드로 받으면 다시 내려받아야 해서 번거롭다. **편번호·길이·용량·전체경로를 표로 찍어 준다.**

완성본은 `volcano_work/일본팬튜브/` 에 쌓이고, 사용자가 올린 편은 그 아래
`업로드/` 로 손수 옮긴다. **`업로드/` 에 있는데 상위 폴더에 더 새 파일이 있으면
그건 내가 나중에 고친 판이다 — 사용자에게 알려 줘야 한다.**


★**완성본 폴더는 「영상 + 메타 텍스트」 짝으로 채운다** (2026-09-11 사용자:
"한 파일에 완성본만 몰아주고 제목 설명글 해시태그도 같이 넣어놔야지").

```
volcano_work/일본팬튜브/
  jp_fantube_ep13.mp4      완성본
  jp_fantube_ep13.txt      【제목】【설명글】【해시태그】 + 引用元
  _제목목록.txt             편번호 - 제목 한 줄 목록
  업로드/                   사용자가 올린 편을 손수 옮기는 곳
```
메타 텍스트는 `scripts/_meta_jp.py` 의 표를 고쳐 다시 돌리면 전 편이 한 번에 갱신된다.
**편을 새로 구우면 그 표에 한 줄 더하는 것까지가 한 편의 완성이다.**
다른 채널 파일이 섞여 있으면 `_소재_다른채널/` 로 뺀다.
