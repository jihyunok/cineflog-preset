2026-10-14 17 그레이하운드: 벤치(U무비)가 원본 70분 「두 번째 어뢰」에서 끊고 「결말은 애플TV에서」로 맺어서 나도 거기서 끊었다(사용자에게 안 묻고 내가 정함). 20분 넘기는 방법으로 「결말까지 넣기」를 고른 뒤 사용자: "왜 결말을 안넣었어?"

**Why:** 사용자는 결말까지 보여 주는 리뷰를 원한다. 가장 재밌는 마지막 전투를 빼면 영상이 짧고 심심해진다.

**How to apply:**
- 영화 리뷰 롱폼은 **결말까지** 넣는다(업로드 제목·설명에 결말포함). 벤치가 결말 전에 끊는 건 따르지 않는다 — 벤치는 장면 순서 길잡이일 뿐.
- 결말을 숨기는 꼴이 필요하면 만들기 전에 사용자에게 묻는다([[talk-before-making]]).
- README 「가장 기본」 5번(결말 범위는 벤치를 따른다)은 이 규칙으로 바뀜.
