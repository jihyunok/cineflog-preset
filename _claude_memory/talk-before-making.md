10-13 인물비화 ep01 을 고치는 중 사용자: "만들지만 말고 이야기좀하고 만들어".
그 전까지 목소리(타입캐스트 미선 1.4 → 제미나이), 대본 덜어 내기, 컷 나누기 등을 말없이 바로 만들어 건넸다.

**Why:** 사용자가 결과를 받고서야 방향이 틀린 걸 알게 되면 두 번 일한다(빠르기·목소리·과장된 끝맺음 모두 사용자가 듣고 나서 지적).
**How to apply:** 목소리·말투·빠르기·썸네일·대본처럼 사용자가 듣고 보는 것을 바꾸거나 새로 정할 때는, 무엇을 어떻게 바꿀지 짧게 말하고(근거 한 줄씩) 고를 것은 보기로 묻고, 대답을 받은 뒤 만든다. 링크만 던진 새 편 시작([[dont-ask-just-do]])과 부딪치면 이 지시가 우선 — 적어도 인물비화([[inmulbihwa-preset]])에서는.
