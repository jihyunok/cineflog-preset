★★10-20 폐지: 사용자 "응 그렇게 해보자 시간은 지킬필요가 없어" — 25분을 채우려고 넣은 일상 대사 토막 때문에 앞 3분 이탈 50%+·평균 시청 3분대. 이제 길이는 맞추지 않고 재미만 본다([[cineflog-first-3min-rule]]). 관문 ⑬ 은 ep.json min_total 을 적은 편만.


2026-10-14 17 그레이하운드를 CID 때문에 대사 창 3초 규칙으로 다시 구웠더니 18:44 → 14:46. 사용자: "14분으로 줄었어?" → "14분으로 줄이면 뭐가 재밌니" → "너 앞으로 영화리뷰할때 20아래로만들지마".

**Why:** 짧아지면 재미가 없다(대사·티키타카가 빠지고 나레만 남음). 강의 체크리스트도 완성 = 원본 20~30%.

**How to apply:**
- 시네플로그 등 영화 리뷰 롱폼은 **20분 정도가 목표**(결말까지 넣고 3초 안 대사를 넉넉히 쓰면 자연히 나온다). 크게 모자라면(15분대) 이야기·대사로 늘리지만, 몇십 초 모자란 걸 억지로 채우지 않는다.
- 늘릴 때는 나레보다 원본 대사(3초 안)·액션 원본 소리·이야기 장면 — 재미 쪽으로. 3초 규칙([[cineflog-cid-transform-all-windows]])은 그대로.
- 줄이는 고침(CID 대응 등)을 하면 길이도 같이 재서 보고한다(14분처럼 크게 줄면 먼저 말한다).

**10-14 고침**: 사용자 "20분정도가되면 좋겠다는거지 억지로맞추지마" — 20분은 목표(정도). 모자라도 억지로 채우지 않는다. gate ⑬ 은 알림만. 17편 최종 19:50.

**★10-17 바뀜**: 다음 영화(20 패밀리 플랜 2) 시작 때 사용자 "25분이상좀만들어줘 조회수가 너무 안나와짧은거는".
- 이제 **25분 이상**이 기준이다. gate.py ⑬ 은 25분(1500초) 아래면 **실패**(ep.json min_total 로 편마다 바꿀 수 있음).
- 늘리는 법은 그대로: 결말까지 · 원본 대사(3초 안) · 액션 원본 소리 · 이야기 장면. 나레로 채우지 않는다(나레 비율 33~45%).
- 강의 규칙 「완성 = 원본 20~30%」와도 맞다(100분 영화 → 25~30분). 대본 dry 길이는 Ludo 가 약 8% 빠르니 27분쯤으로 잡는다.
