2026-10-13 사용자(시네플로그 16 핀치 v8): "4분54초에 고 가 따로 붙어있어 중간에 영상이잠깐씩 멈추는것도 보이던데 왜그래?" → "8분12초그 곳까지 이렇게 나와" → "왜자꾸 이런게 나오는거야".

원인 1 (나레): 제미나이 TTS 로 여러 문장을 한 wav 에 뽑고 gem_split 이 Groq 받아쓰기 낱말 끝 시각에서 잘랐는데, 받아쓰기 시각이 0.1~0.3초 일러서 경계가 소리 한가운데 떨어졌다 → 「있었고」의 「고」 꼬리가 다음 조각 맨 앞에 따로, 「그곳까지」의 「그」 머리가 앞 조각 끝에 따로 붙음. 148조각 중 27경계 + 9번 머리.
원인 2 (멈춤): 빈자리가 없을 때 앞 컷 끝 그림을 멈춰 세우는 hold 를 18곳(최장 2.9초) 넣었다 → 화면이 얼어붙어 보임.

**Why:** 사용자는 한 곳을 짚지만 같은 원인이 전 구간에 깔려 있었다. 한 곳씩 지적받게 하면 "왜 자꾸"가 된다.
**How to apply:**
- 나레를 여러 문장 한 번에 뽑아 자르면 굽기 전에 `narr_recut.py --dry`(원본 wav 소리 크기로 경계 검사: 경계 뒤 0.35초 안 토막+쉼 → 앞 문장 끝 / 경계 앞 0.15초 안 토막 → 다음 문장 머리 / 소리 속 → 가장 조용한 곳) → `narr_recut.py` → `realign.py` → `narr_frag.py`(조각마다 앞뒤 토막 0개, 남은 건 Groq 로 받아써서 온전한 낱말인지 확인). 도구: presets/시네플로그/ep16v5_핀치/.
- 화면 멈춤(hold)은 쓰지 않는다. 메울 때는 fix9_v8.py 순서: 그 컷 원본 더 틀기 → 다음 컷 앞당기기(말·자막 시각 고정) → 같은 장면·장소·차림 빈자리 컷 끼우기 → 뒤 액션 컷 묶음을 0.88배 이상으로 살짝 느리게. check_all ⑦ 멈춤 0 확인.
- 같은 «멈춘 듯 보임»: 원본이 까만 화면(정전·암전)인 창이 벤치는 그림 있는 자리에서 까맣게 서 있는 것 → 완성본 blackdetect + fix10_v8.py(액션 창은 옮김, 대사 창은 그림만 vs). 건네기 전 freezedetect(-72dB)·blackdetect 둘 다 돌리고 벤치와 견준다.
