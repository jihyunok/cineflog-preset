글 여러 건을 판정·분류·거르기·줄 세우기 하는 일은 **기본으로 제브(Jev)를 먼저** 쓴다 (규칙·도구: `volcano_work/_제브/CLAUDE.md`). 채널 분석의 편별 소재·이야기 축·첫 문장 꼴 분류, 벤치 후보 채널 거르기도 포함.

**Why:** 10-13 유광의 이야기 131편 분석을 제브 없이 클로드가 직접 분류함 → 사용자 "너 제브사용하니" → "기본적 제브는 사용해".
**How to apply:** 분석·소재 고르기에서 보기 고르기·예/아니오·점수가 나오면 제브 판정부터 돌리고, 세기·계산은 코드, 글쓰기는 클로드. 벤치 채널 제목·대본(남의 글)을 제브에 보내는 것도 이 지시로 허락된 것으로 보고 매번 묻지 않는다(개인 정보는 가림). 관련: [[yugwang-story-channel-analysis]] [[bench-copy-everything]]
